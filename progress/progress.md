## 错题本
（考察答错的知识点记录在这里，复习时优先看）

### 第 1 讲（2026-09-03）
1. **~ 是家目录不是根目录**：`cd ~/..` 的结果：~ 展开为 /home/Math_lover，向上一级是 /home（答成 / 了）
2. **目录的 x 权限 = 进入/穿越**：进入并列出目录内容需要 r+x 两个权限（只答了 r）
3. **sudo 管不到重定向**：`>` `<` 由当前用户的 shell 执行，sudo 只提升后面的程序；root 文件要用 `sudo tee`（Q5 完全未掌握，已重讲+补考）
4. **bash 里 # 开头的词是注释**：`echo #!/bin/sh` 中的 #!/bin/sh 被当注释吃掉，写入的是空行；含特殊字符的文本必须用单引号 `echo '#!/bin/sh'`
5. **chmod 用法**：`chmod +x 文件`（u/g/o +/- r/w/x），补考中
6. **"\< 是低级权限"是错误心智模型（补考1次错）**：`<` `>` 只是接水管的符号，本身无权限概念；规则是"谁打开文件，就用谁的权限"——`sudo cat < file` 里开文件的是普通用户的 shell，`sudo cat file` 里开文件的是 root 的 cat
7. **目录 x 权限（第2次错）**：`drwx-----x` 时其他人**能 cd 进入**（x=门禁卡），**不能 ls**（r=索引牌）；已给决定性实验（chmod 701 + chown root）待跑

### 第 2 讲（2026-09-03）
1. **$? 是退出码，不是参数**（和 $0/$1-$9 混淆）：$? 存上一条命令的退出码，**0 = 成功**，非 0 = 失败（127 找不到命令、130 被 Ctrl+C）；尚未掌握
2. **|| 语义**：前一条【失败】才执行——"兜底/否则"；touch 失败时 `touch a || ls` 的 ls **会**执行；脚本经典用法 `cd dir || exit 1`（✅ 补考已掌握 2026-09-03）
3. **foo = bar 只背了规则没讲机制**：bash 空格解析成"运行程序 foo，参数 = 和 bar"→ foo: command not found（规则背后的机制是第 1 讲的空格解析）
4. **【系统性弱点·已出现3次】分不清"shell 层"和"程序层"**：① `>` 重定向是 shell 干的不是程序（L1-Q5）② `*` glob 是 shell 展开不是 find 匹配（L2-Q3）③ `&&` 是 shell 连接两条完整命令的，不能放进 find 当条件（L2-R1）。find 内部逻辑：条件并列=且，`-o`=或，`!`=非
5. **读题不细**：要求找 >100MB，写成 +10M（L2-R1）
6. **"ssh 重启导致任务没了"是错误机制**（L2-Q5a）：真实原因 = 断线 → 远端 sshd 给登录 shell 发 **SIGHUP**（挂断信号）→ shell 死 → 子进程（任务）被清理。tmux 原理 = client/server 分离：任务挂在 tmux server 下，断线只杀 client
7. **L1 基础命令开始遗忘**（cp 忘了）：与跳过验证实验相关；对策 = 主动回忆练习 + 之后每讲随机抽查旧知识（"学长突袭"）；已要求默写文件操作四件套（cp/mv/mkdir/rm）
8. **bash 的 `{` 是保留字（reserved word）不是符号**（L2-Q4 调试实战）：必须独立成词——`{echo` 被解析成一个名叫 `{echo` 的命令而非"开块"；一个缺失空格导致"函数体提前闭合 → 顶层误执行 cp(line3) → line4 多余 } 报错"两个症状。纪律：`name () {` 带空格、`}` 独占一行
9. **source vs ./（✅ 2026-09-04 第4次讲解后掌握）**：学生最终自述正确——./=子shell跑完不影响主shell，source=主shell亲自执行；已补讲设计原因（进程隔离默认安全，source=明示信任；子进程只能回传 stdout+退出码；./=pass-by-value，source=this->方法）
10. **Q5 tmux/SIGHUP 教过 1 次即忘**：与进程树模型合并讲解（source 与 tmux 是同一张图）
