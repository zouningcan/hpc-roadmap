## 一、超算比赛比什么

### 世界三大大学生超算竞赛

| 竞赛 | 主办/地区 | 队伍规模 | 赛制特点 |
|------|-----------|----------|----------|
| **ASC**（ASC 世界大学生超级计算机竞赛，Student Supercomputer Challenge） | 中国发起，亚洲超算社区 | 全球 300+ 支高校队伍报名 | 预赛提交**集群设计方案 + 应用优化方案** → 决赛在 **3000W 功耗约束**下现场搭建集群并优化赛题 |
| **SC SCC**（Student Cluster Competition，超级计算大会学生集群竞赛） | 美国 SC 会议 | 每队 6 名学生 + 1 名指导老师 | **48 小时连续挑战**：自带/合作厂商提供硬件，功耗封顶，跑基准 + 科学应用 |
| **ISC SCC**（ISC 学生集群竞赛） | 德国 ISC 会议 | 全球 20–26 支队伍 | 线上 + 线下结合，赛题贴近真实科研 HPC 系统 |

国内还有"全国并行应用优化大赛（CAE/PAC）"等同类型赛事，赛题风格类似。

### 比赛内容拆解（三大竞赛通用）

一场超算比赛 = **自己搭一台小超算 + 在限电条件下把它跑得尽可能快**。具体分四块：

1. **集群搭建（Cluster Setup）**
   - 在物理机上装 Linux（多为 Ubuntu/CentOS/Rocky）、配置网络（InfiniBand/Ethernet）、NFS 共享、环境变量、编译器链（GCC/Clang、MPI 实现）
   - 作业调度器：**Slurm** / PBS
   - 决赛现场还要考虑**功耗墙**：3000W 内平衡 CPU 频率、节点数、GPU 数量

2. **基准测试（Benchmarks）**
   - **HPL**（High Performance Linpack）：刷 LINPACK 分数，调 BLAS 库（如 OpenBLAS/AOCL/oneAPI MKL）、矩阵规模、分块、进程/线程映射
   - **HPCG**：共轭梯度法基准，更贴近真实内存密集型负载，优化空间大
   - 部分比赛还考 HPL-MxP（混合精度 Linpack）、IO500（存储）等

3. **应用赛题（Application Optimization）**——分差所在
   - **AI 类**：大语言模型（LLM）训练/推理优化、AIGC、具身智能；近年 ASC 赛题如 YYLM 大模型、DeePMD（分子动力学）、AI 交通预测
   - **AI for Science / 传统科学计算**：WRF-Hydro（水文模式）、引力波数值模拟、基因组装等，代码多为 **C/C++/Fortran**
   - 优化手段：**MPI**（进程级并行）、**OpenMP**（节点内多线程）、**CUDA/HIP**（GPU 异构计算）、SIMD 向量化、性能剖析（perf、Nsight、VTune）

4. **方案与答辩**
   - 预赛要写集群设计方案（选硬件、算功耗、预算），决赛后要向评委（含 HPC 业界专家）英文/中文答辩

> 一句话：**Linux 运维 + 并行编程 + 计算机体系结构 + 一点 AI 系统知识**，四样都要会一点，再选一个方向钻深。

## 二、复旦超算队推荐的四门课（图中路线）

图中路线是四步递进：**计算机基础 → C/C++ → 数据结构与算法 → HPC/Infra 进阶**。

### 阶段 1：入门综合 —— MIT《The Missing Semester of Your CS Education》

- **官网**：[missing.csail.mit.edu](https://missing.csail.mit.edu/)（有[中文翻译版](https://missing-semester-cn.github.io/)，B 站有中文字幕）
- **定位**：教课堂上不教、但天天要用的"工具课"，共 11 讲
- **内容**：
  1. 课程概览与 Shell 基础
  2. Shell 工具与脚本（管道、重定向、bash 脚本）
  3. 编辑器（Vim）
  4. 数据整理（grep/awk/sed/pipes）
  5. 命令行环境（任务控制、tmux、dotfiles、ssh）
  6. 版本控制（Git，深入到 rebase/reflog）
  7. 调试及性能分析（print 调试、gdb、profiling）
  8. 元编程（构建系统 make、依赖管理、CI/CD）
  9. 大型实例演示
  10. 安全与密码学
  11. 杂项（daemon、备份、API、FUSE 等）
- **为什么先学它**：超算比赛全程在 Linux 集群上操作——连不上集群、看不懂报错、不会写 slurm 脚本，后面一切免谈。Shell、SSH、Git、调试是进场门票。
- **学法**：2–4 周，每讲 1 小时视频 + 动手做习题，**必须开一台 Linux（虚拟机/WSL2/服务器）边看边敲**。

### 阶段 2：C 语言基础 —— Stanford《CS106B: Programming Abstractions》

- **官网**：[cs106b.stanford.edu](https://cs106b.stanford.edu/)（往期材料见 [keithschwarz.com/cs106b 存档](https://www.keithschwarz.com/cs106b/)，B 站有课程录像）
- **定位**：斯坦福编程序列第二门课，用 **C++** 教"编程抽象 + 问题求解"
- **内容**（按周）：
  - C++ 基础语法、STL 集合类（Vector/Map/Set/Queue/Stack）
  - **递归**（全课程灵魂：递归下降、穷举搜索）
  - **递归回溯（Recursive Backtracking）**：迷宫、八皇后、单词搜索类问题
  - **Big-O 时间/空间复杂度分析**
  - 排序算法（选择/插入/归并/快排）
  - 面向对象与数据抽象、指针与内存模型
- **为什么重要**：HPC 应用赛题的代码几乎都是 **C/C++/Fortran**。指针、内存布局、编译链接这些 C++ 功底不牢，后面读 MPI/CUDA 代码会非常痛苦。
- **学法**：6–8 周，重点把每次 **assignment 完整做掉**（斯坦福的作业质量极高）。已有 C 语言基础的同学可以加速，重点补递归和内存模型。

### 阶段 3：数据结构与算法 —— 清华邓俊辉《数据结构》

- **官网/平台**：[学堂在线 数据结构（上）](https://www.xuetangx.com/course/THU08091000384)、[数据结构（下）](https://www.xuetangx.com/course/THU08091002048)，[课程 MOOC 主页](https://dsa.cs.tsinghua.edu.cn/~deng/ds/mooc/)
- **教材**：邓俊辉《数据结构（C++ 语言版）》（电子版在课程主页免费开放）
- **内容**：向量、列表、栈与队列、二叉树、**BST/AVL/B 树**、优先级队列与堆、哈希、**图**（遍历、最短路、最小生成树）、**排序**（含基数排序等高级话题）、串（KMP）
- **为什么重要**：两个作用——① 算法复杂度思维，做性能优化时知道瓶颈在哪；② HPC 应用（如图算法、网格计算、稀疏矩阵）本质就是这些数据结构在大规模并行下的变体。
- **学法**：8–12 周，上下两册。可以和阶段 2 部分并行（C++ 学到能写类就可以开这门）。做题可上清华 OJ 或 PTN 平台。

### 阶段 4：HPC / Infra 进阶 —— UCSD《CSE 234》

- **官网**：[haoailab.com/cse234-w25](https://haoailab.com/cse234-w25/)（讲义、录像、作业公开；Spring 2026 起改名 [CSE/DSC 234: Data-Centric AI and AI Engineering](https://cseweb.ucsd.edu/classes/sp26/cse234-a/)，课程有[公开 GitHub 仓库](https://github.com/hao-ai-lab/cse234-w25)）
- **注意**：这门课实际名称是 **"Data Systems for Machine Learning"**（Hao Zhang 老师，hao-ai-lab），不是传统 MPI 课——它讲的是 **GPU 计算 + 机器学习系统**：GPU 性能模型、矩阵乘优化、算子编译、大模型推理/训练系统（这与海报把它归为 "HPC/Infra 进阶" 一致，因为现代超算比赛的赛题重心已大量转向 **AI/LLM 优化**）
- **内容**：GPU 架构与性能剖析、matmul 优化（分块、tensor core）、算子编译（compiler for ML）、并行训练/推理系统、数据系统与 ML 的结合
- **为什么放最后**：直接对应比赛里分值最重的 AI 赛题（LLM 推理优化、AIGC），也是当前 HPC 与 AI 融合的主线。
- **学法**：先修要求较高（需要系统 + CUDA 基础），建议在前三门完成后配合 CUDA 实践学习。

## 三、四门课之外必须补的"比赛硬技能"（自主补充）

海报的四门课是地基，比赛本身还需要以下专项训练（各校超算队入队后老带新练的就是这些）：

1. **并行编程三件套**
   - **MPI**（跨节点消息传递）：集合通信、点对点、通信域划分 —— 入门书《并行程序设计导论》（*An Introduction to Parallel Programming*）
   - **OpenMP**（节点内共享内存多线程）：parallel/for、schedule、reduction
   - **CUDA**（GPU 异构计算）：线程层次、显存层次、shared memory 优化 —— 推荐 **PMPP**（*Programming Massively Parallel Processors*）+ NVIDIA 官方 [CUDA C++ Programming Guide](https://docs.nvidia.com/cuda/cuda-c-programming-guide/)
2. **HPL/HPCG 实战调优**：在集群上从零跑通 LINPACK，调 BLAS、矩阵规模、进程映射；HPCG 调内存访问模式
3. **性能剖析**：perf、Nsight Systems/Compute、VTune——先测量再优化
4. **集群运维**：Slurm 调度、编译器与库管理（module/Spack）、InfiniBand 基础
5. **AI 推理框架**：vLLM、TensorRT-LLM、PyTorch 分布式训练（对应 CSE234 内容）

**免费练手资源**：
- [HUST 高性能计算学习路线](https://heptagonhust.github.io/HPC-roadmap/)（华科超算队整理）
- [浙大超算队 ZJUSCT 技术指南](https://www.zjusct.io/guideline/)（真实竞赛经验，含 ASC 备赛资料）
- [上海交大 HPC 学生培养白皮书](https://apps.hpc.sjtu.edu.cn/whitepaper/student.html)
- [天河二号"超算习堂"免费实训平台](http://www.nscc-gz.cn/newsdetail.html?7937)（预装 MPI/OpenMP/CUDA/PyTorch 环境）
- [ASC 入门 Wiki](https://cswu-challenge.github.io/wiki/ASC-introduction/)

## 四、一步步学习计划（可执行版）

假设每周投入 10–15 小时：

| 时间 | 任务 | 产出验收标准 |
|------|------|--------------|
| 第 1–3 周 | **Missing Semester** 全部 11 讲 | 能用 ssh + tmux + git 管理 Linux 机器；会写 bash 脚本批量任务 |
| 第 4–9 周 | **CS106B**（C++ + 递归 + 复杂度） | 完成全部 assignments；能手写快排、会用 STL、理解指针与栈/堆 |
| 第 10–20 周 | **清华数据结构**（上+下） | 学完到图与排序；能在 OJ 上独立解中等难度题 |
| 第 21–24 周 | **并行编程入门**：MPI + OpenMP | 用 MPI+OpenMP 混合写并行矩阵乘、求 π、Monte Carlo；跑通 HPL |
| 第 25–30 周 | **CUDA**（PMPP 前 10 章）+ CSE234 讲义 | 手写优化 SGEMM；理解 GPU 性能模型；跑通一个 LLM 推理 demo |
| 之后 | 比赛实战：刷历年 ASC/SC/ISC 赛题，进队老带新 | 能独立负责一个赛题的优化报告 |

**学长建议**：
- 前三个阶段是"地道地基"，不要跳。C++ 和数据结构不牢，HPC 阶段全是天书。
- 阶段 4 开始时，最好手里有一台能摸 GPU 的机器（实验室服务器、云 GPU、或学校集群）。
- 想参加 ASC27 的话，关注每年 9–12 月的报名窗口；预赛主要靠写方案 + 远程优化，进队前把 Linux 和 C++ 搞扎实就是最大竞争力。
- 以上课程均在 Google / 必应直接搜课号即可找到官网（海报原话）。
