# 课程溯源与资源谱系

> **本文档回答一个问题：这个仓库里的每一份讲义，源头是谁？**
> 仓库生产流水线 = *官方教材（联网搜索/抓取）→ 浓缩讲义 → 教育性分层练习*。这里是流水线的进料清单：路线图的来历、每个模块对应的官方章节、以及按主题归档的扩展读物。
> 查证时间：2026-09-03 ~ 09-05。链接失效时按课号搜索即可找到新版官网。

### stage2 · CS106B（官方 28 讲 → 14 模块）

按官方 L1-L28 聚类，映射表见 [stage2-cpp/README.md](../stage2-cpp/README.md)（每模块标注对应讲次，如 07-backtracking = L11-L12）。环境对齐说明也在该 README：官方 Qt Creator + Stanford 库 → 本仓库 WSL + `g++ -std=c++17` + 纯标准库，Stanford 专属函数给出 std 等价实现。

### stage3 · 清华邓俊辉《数据结构》（教材目录 → 11 模块）

- **抓取受限说明**：课程官网为 GB 编码 + JS 渲染，无法直接抓取讲义正文。各模块结构依据**教材目录与 MOOC 公开大纲**整理；已抓到的官方 FAQ 元信息（OJ 仅 C++、禁 STL、60% 习题 + 40% 编程）存于 [01-fundamentals](../stage3-dsa/01-fundamentals/) 讲义附录。
- 教材：《数据结构（C++ 语言版）》第三版，电子版在[课程主页](https://dsa.cs.tsinghua.edu.cn/~deng/ds/mooc/)免费开放。
- **OJ 精神**：清华 OJ 禁用 STL、要求手写一切数据结构——本阶段全部练习遵守此传统（与 stage2 会用 STL 形成对照）。
- 模块 01-07 已完成；08 优先级队列、09 散列、10 图、11 排序待建（见 [stage3-dsa/README.md](../stage3-dsa/README.md)）。

## 四、真题锚点：交大 HelloHPC 第一届选拔

备考的对标真题（2026-09-04 分析完毕，存于本地 hello-hpc/ 目录）。10 题与本路线的映射：

| 真题 | 考什么 | 对应本仓库 |
|------|--------|------------|
| 1-2 | SSH 指纹、Missing Semester 工具链 | stage1 模块 05/06 等 |
| 3-6、9 | C++、算法、位运算 | stage2 全部 + stage3 |
| 7 | CSE234 内容 | stage4 模块 07 |
| 8、10 | 并行/集群实操（ARM 鲲鹏 + NEON） | stage4 模块 01/05/06 |

> 迁移提示：真题平台是 ARM 鲲鹏（aarch64），x86 本地练习时向量化代码要用 NEON intrinsic 重写（`vaddq_s32` 一族），stage4 模块 06 会展开。

## 五、排版约定（全仓库统一）

- 每模块三件套：`notes.md`（讲义，头部标注来源链接）+ `exercises.md`（A 概念/B 动手/C 挑战三层，每题标考察点）+ `solutions.md`（含答案与解析）
- 🕷 标记 = 实战教学中真实踩过的坑（错题回填），区别于教材原始内容
- 状态标记：✅ 完成 ｜ 🔄 进行中 ｜ ⬜ 待建 ｜ ⏭️ 跳过
- 行尾统一 LF（`.gitattributes` 强制）；中文标点、术语首现标英文原文
