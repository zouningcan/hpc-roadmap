## 0. 一句话定位与为什么现在学

集群是纯命令行环境：ssh 上去改配置、改脚本、改编译选项，没有图形编辑器可用。**Vim 是超算比赛的编辑器底线**。学习曲线：约 2 小时入门，20 小时追平旧编辑器效率，之后持续反超。它的设计思想影响深远（VS Code 的 Vim 插件约 140 万安装量）——就算日后主力用别的，Vim 手感也是随身资产。

## 1. 模态编辑（modal editing）：Vim 的核心反直觉设计

写代码时**读/改远多于打字**，所以 Vim 让按键"一键多用"：同一个键在不同模式下含义完全不同（`x` 在插入模式输入字母，正常模式删字符，可视模式删选区）。

| 模式 | 进入方式 | 用途 |
|------|----------|------|
| **正常模式**（默认） | （开机即在此） | 移动光标、下达编辑命令 |
| 插入模式 | `i`（`a` 光标后、`o` 下方新行、`O` 上方新行） | 输入文本 |
| 替换模式 | `R` | 覆盖输入 |
| 可视模式 | `v`（字符）/ `V`（行）/ `Ctrl-v`（矩形块） | 选中文本再操作 |
| 命令模式 | `:` | 保存/退出/搜索替换等 |

**ESC 从任何模式返回正常模式**。强烈建议把 **Caps Lock 重映射为 ESC**（小拇指一压就到，这是 Vim 手感的第一投资）。

**新手第一关——怎么退出**：`:q` 退出、`:w` 保存、`:wq` 保存退出、`:q!` 不保存强退、`:e 文件名` 打开、`:ls` 列出缓存、`:help 标题` 查帮助。

## 2. 核心心智模型：Vim 是一门语言

把按键组织成**"动词 + 名词（+ 计数）"的语法**，你就不再是背命令，而是"说句子"：

**名词（移动 = 操作对象）**：

| 键 | 含义 | 键 | 含义 |
|----|------|----|------|
| `h j k l` | 左 下 上 右 | `w / b / e` | 下一词首 / 词首回退 / 词尾 |
| `0 / ^ / $` | 行首 / 首个非空字符 / 行尾 | `gg / G` | 文件头 / 文件尾（`42G` 跳 42 行） |
| `f{字符}` | 行内下一个该字符（`;` 重复 `,` 反向） | `%` | 跳到配对括号 |
| `/{模式}` | 搜索，`n` 下一个 `N` 上一个 | `Ctrl-u/d` | 上/下翻半页 |

**动词（编辑动作）**：

| 键 | 含义 | 键 | 含义 |
|----|------|----|------|
| `d{移动}` | 删除（`dw` 删词、`d$` 删到行尾=shift 不用按） | `c{移动}` | 改变 = 删除后进插入（`cw`） |
| `x` | 删单字符（= `dl`） | `s` | 替换字符（= `xi`） |
| `y` / `p` | 复制 / 粘贴 | `u` / `Ctrl-r` | 撤销 / 重做 |
| `.` | **重复上一次修改**（被低估的神键） | `~` | 切换大小写 |

**计数插入中间**：`3w`（跳 3 词）、`7dw` 或 `d7w`（删 7 词）。

**修饰语（文本对象）**：`i` = 内部、`a` = 连周围一起——

- `ci(` 改括号**内**的内容（change inside parens）
- `ci[` 改方括号内、`ci"` 改双引号内
- `da'` 连引号一起删（delete around quotes）

读代码改参数全靠 `ci(` 和 `ci"`，一次按键替代"定位括号→数光标→删半天"。

## 3. 缓存（buffer）vs 窗口（window）vs 标签页

Vim 同时打开多个**缓存**；**窗口只是缓存的视图**——同一个缓存可以显示在多个窗口里（对照同一文件的两处，改超长配置文件时救命）：

```vim
:sp           " 水平分屏
:vsp          " 垂直分屏
:ls           " 列出所有缓存
:e file.txt   " 打开/切换文件
```

## 4. 搜索与替换

```vim
/printf        " 搜索 printf，n/N 跳转
:%s/foo/bar/g  " 全文把 foo 替换为 bar
:%s/\[.*\](\(.*\))/\1/g   " 正则例：Markdown 链接 [text](url) → url
```

`%s` = 对全文做替换（substitute），`g` = 行内所有匹配（不加只换每行第一个）。

## 5. 宏（macro）：把重复劳动录下来

```vim
qa      " 开始录制宏，存入寄存器 a（做一套操作）
q       " 停止录制
@a      " 重放一次
5@a     " 重放 5 次
```

**宏出错即停**；可递归调用（先 `qaq` 清空再录制含 `@a` 的宏）。给 100 行统一加前缀、批量注释这类活，录一次放到底。

## 6. 自定义：~/.vimrc 与插件

- `~/.vimrc` 是纯文本配置，每次启动自动加载。**读别人的配置、只采纳看得懂的部分，不要整体复制**
- 插件（Vim 8.0+ 原生支持）：丢进 `~/.vim/pack/vendor/start/` 即可（可 git clone）。常用：ctrlp.vim（模糊找文件）、ack.vim（代码搜索）、nerdtree（文件树）

入门三行配置（先用这三行，理解了再加）：

```vim
set nu            " 显示行号
set hlsearch      " 搜索高亮
set shiftwidth=4  " 缩进 4 空格
```

## 8. 常见误区清单

1. **默认模式是正常模式不是插入模式**——打开 Vim 直接打字会触发一堆命令（新手"卡死"的根源）；先 `i` 再打字
2. 退不出来不是笑话：`:q!` 永远能逃出生天
3. 用方向键不算错，但等于放弃了 Vim 一半的价值——手别离开主键区
4. `.vimrc` 整体复制网上的"神配置" = 一堆你不懂的魔法，出错无从排查
5. `u` 能撤销，`Ctrl-r` 能重做——放心实验
