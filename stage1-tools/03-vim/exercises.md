# 模块 03 练习：编辑器（Vim）

> 本模块练习以动手为绝对核心。**A 卷概念分占三成，B 卷动手占七成**——Vim 没有捷径，只有肌肉记忆。
> 环境：WSL 终端，`vimtutor` 命令自检可用。

## A 概念题

**A1** Vim 为什么设计成"模态"的？它对"编程时读和写哪个多"做了什么假设？
*考察点：模态编辑的设计动机（读/改多于打字 → 按键复用）。*

**A2** 用"动词 + 名词"语法拆解下面四个操作，说出各自做什么：
`dw`、`d$`、`ci(`、`da'`
*考察点：Vim 作为语言的组合语法，而非死记命令。*

**A3** 缓存（buffer）和窗口（window）是什么关系？"同一个文件开两个窗口对照编辑"为什么可行？
*考察点：窗口是缓存的视图，非一一对应。*

**A4** 解释 `:%s/foo/bar/g` 每一段的含义：`%`、`s`、`g` 分别是什么？去掉 `g` 行为怎么变？
*考察点：替换命令结构。*

**A5** 为什么老手建议把 Caps Lock 重映射为 ESC？
*考察点：ESC 使用频率与手指经济学的直觉。*

## B 动手题

**B1（核心练习，官方第 1 题）** 终端输入 `vimtutor`，完成全部章节（约 30–40 分钟）。完成后用一句话总结每章主题（共 7 章）。
*考察点：Vim 基本功。这是本模块唯一不可替代的练习。*

**B2（最小按键挑战）** 准备文本：
```bash
mkdir -p ~/ex/vimtest && cd ~/ex/vimtest
cat > play.txt <<'EOF'
int main() {
    int count = 100;
    printf("hello world", name);
    return 0;
}
EOF
vim play.txt
```
在 Vim 中完成以下修改，**每小题记下你用的按键序列**（从正常模式算起，编辑完 ESC）：
1. 把 `100` 改成 `42`
2. 把 `hello world` 改成 `bye world`（提示：`ci"`）
3. 删除 `return 0;` 这一整行（提示：`dd`）
4. 在 `}` 的上一行插入新行 `    fflush(stdout);`（提示：`O` 或定位后 `o`）
5. 全文把 `int` 替换为 `long`
*考察点：动词名词组合、文本对象 ci"、dd、o/O、:%s。数按键不是为了比赛，是为了逼你放弃"方向键+退格"的旧习惯。*

**B3（分屏对照）** 用 `:vsp` 把 play.txt 分成左右两窗，光标在两窗间切换（`Ctrl-w w`），体验"同一缓存两个视图"。
*考察点：buffer/window 关系的手感。*

**B4（搜索跳转，读代码基本功）** 在 `/usr/include/stdio.h`（或 WSL 里任意系统头文件）中：
1. 搜索 `printf` 的声明并跳转（`/printf` + `n`）
2. 从某个 `(` 跳到它的配对 `)`（`%`）
3. 直接跳到文件第 100 行（`100G`），再跳到文件尾（`G`）、文件头（`gg`）
*考察点：读大文件的浏览动作，比赛读赛题代码的日常。*

## C 挑战题

**C1（宏）** 造 20 行 `item_<n>` 文本，用宏给每行行首加 `# `（注释掉）：
```bash
for i in $(seq 1 20); do echo "item_$i"; done > ~/ex/vimtest/items.txt
```
要求：录制一个宏（`qa ... q`），然后用 `@a` 和计数（如 `19@a`）一次完成，不许手动逐行。
*考察点：宏录制/重放；`0` 回行首 + `I` 行首插入的组合。*

**C2（官方替换进阶）** 有如下 Markdown 文本若干行：
```
[Google](https://google.com)
[MIT](https://mit.edu)
```
用一条 `:%s/.../.../` 把每行变成只剩 URL（`https://google.com`）。提示：正则分组 `\(...\)` 捕获，替换里用 `\1`。
*考察点：替换命令 + 分组捕获；官方讲义的演示例子。*

**C3（自己的 vimrc）** 给 `~/.vimrc` 加上三行配置（行号、搜索高亮、4 空格缩进），**逐行解释每行作用**，然后说明：这个文件什么时候被读取？为什么改完要重启 vim（或 `:source ~/.vimrc`）？
*考察点：配置机制；source 概念在 Vim 里的再现（模块 02 知识迁移）。*
