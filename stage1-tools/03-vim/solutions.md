# 模块 03 参考答案

## A1

编程时**阅读、浏览、修改远多于连续打字**。模态设计让每个键位在不同模式下承载不同功能：正常模式专职"移动+下达编辑命令"，按键无需与"输入文字"共享——于是 `d`、`c`、`y` 这些"动词"和移动组合成语言，且全程不用碰鼠标甚至方向键，目标是"编辑速度跟上思维速度"。

## A2

| 操作 | 拆解 | 含义 |
|------|------|------|
| `dw` | delete + word | 删掉从光标到下一个词首（删一个词） |
| `d$` | delete + 到行尾 | 从光标删到行尾（等价 shift+d 的 `D`） |
| `ci(` | change + inside + 括号 | 删掉当前括号**内**的全部内容并进入插入模式 |
| `da'` | delete + around + 引号 | 连引号带内容一起删 |

要点：`c` = `d` + 进入插入；`i` 只含内部、`a` 连周围包裹符一起。

## A3

窗口是缓存的**视图**，不是缓存本身。一个缓存可以同时显示在多个窗口（`:sp`/`:vsp`），滚动、编辑同步（因为是同一份数据），适合对照同一文件的两个远距离位置。反过来多个缓存（`:ls` 可见）也可以只显示在一个窗口里。

## A4

- `%` = 作用范围是全部行（等价 `1,$`）
- `s` = substitute 替换命令
- `g` = global，行内**所有**匹配都替换
- 去掉 `g`：每行只替换**第一个**匹配

## A5

ESC 是"返回正常模式"，是 Vim 里频率最高的按键之一，却在键盘角落；Caps Lock 正好在左手小拇指原位、几乎无其他高频用途。把一个"每分钟按多次"的键挪到小拇指下，是收益最高的单笔手感投资。

## B2 参考按键（不唯一，够短即可）

1. 改 100→42：`/100<回车>` 然后 `ciw42<ESC>`（或 `cw42<ESC>`）
2. hello→bye：`f"` 不必——直接 `ci"bye world<ESC>`（光标先放到该行引号内：`/"hello<回车>` 或 `j` 定位）
3. 删整行：`/return<回车>` 然后 `dd`
4. 上插一行：`G` 到 `}` 行，`O`，输入 `    fflush(stdout);`，`<ESC>`
5. 全文替换：`:%s/int/long/g`（注意会把 `printf` 里的……不会，`printf` 不含独立 `int`？——含！pr**int**f。正确做法：`:%s/\<int\>/long/g` 用词边界锚定，这是本题埋的陷阱：朴素替换会把 `printf` 破坏成 `prlongf`）

## B3

`:vsp` 后两窗内容同步滚动编辑；`Ctrl-w w` 切换焦点；`Ctrl-w h/j/k/l` 按方向切窗。体验要点：改一边另一边立即变——同一份缓存数据。

## B4

- `/printf` 回车，`n` 逐个下一个，`N` 反向
- 光标放任意 `(` 上按 `%` 跳到配对 `)`，再按 `%` 跳回
- `100G` → 第 100 行；`G` 文件尾；`gg` 文件头

## C1 参考流程

光标放第 1 行行首，`qa`（录制）→ `0I# <ESC>j`（行首插 `# `，下移一行）→ `q`（停止）→ `19@a`（对余下 19 行重放）。
要点：宏末尾的 `j` 是让"重放后光标停在下一行"，宏才能接续工作；`I` = 行首（首个非空字符前）插入。

## C2 参考

```vim
:%s/\[.*\](\(.*\))/\1/g
```

拆解：`\[.*\]` 匹配方括号及文字（`[` 需转义），`(` 字面括号，`\(.*\)` **分组捕获** URL，`)` 字面括号；替换为 `\1` = 第一个分组的内容。

## C3 参考

```vim
set nu            " 显示行号（:set number 的缩写）
set hlsearch      " 搜索词高亮
set shiftwidth=4  " 自动缩进步长 4 空格
```

`.vimrc` 在 **Vim 启动时**被自动读取执行（类比 `~/.bashrc` 对 bash 的关系——都是"启动时加载的个人配置"）；已开着的 Vim 不会自动重读，所以要么重启、要么手动 `:source ~/.vimrc`。这正是模块 02 "source = 亲自逐行执行"的又一次出现。
