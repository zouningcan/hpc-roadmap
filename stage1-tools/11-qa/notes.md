# 模块 11：提问&回答（Q&A）——stage1 综合复习

## 1. 工具学习的优先级（官方答案）

**键盘优先于鼠标 → 深度掌握编辑器 → 自动化重复任务 → 精通版本控制**。对照路线图：模块 03（Vim）→ 全部 shell 模块 → 模块 06（Git）——你已经按这个顺序走完了。

## 2. Python 还是 Bash？（模块 02 的深化）

**Bash 适合"短小的一次性命令序列"**。它的短板：边界情况脆弱（空格、引号）、没有真正的代码复用/库生态、靠 `$?` `$@` 这类"魔法字符串"而非显式命名。**脚本变大就换语言**：Python/Ruby，或"哪个语言有你需要的库就用哪个"。

判据一句话：**超过 ~50 行、需要数据结构、要复用逻辑 → 离开 bash**。

## 3. source vs ./（模块 02 核心）

官方答案原文：`source` 在**当前 shell** 里执行，cd、函数定义等改动**保留**；`./script.sh` 另起一个 bash 实例，退出后改动**消失**。——你做过 cd 实验的那个考点，官方 Q&A 又问了一遍，说明它是全人类共同的坑。

## 4. 程序都在哪？FHS 目录标准（模块 01 的补全）

可执行文件来自 `$PATH` 里的目录（`which`/`type` 定位）。**文件系统层级标准（FHS, Filesystem Hierarchy Standard）**：

| 目录 | 内容 | 目录 | 内容 |
|------|------|------|------|
| `/bin` | 基础可执行 | `/etc` | 系统配置 |
| `/sbin` | root 系统工具 | `/home` | 用户家目录 |
| `/lib` | 系统库 | `/tmp` | 临时（重启清空） |
| `/dev` | 设备文件 | `/var` | 日志/缓存 |
| `/opt` | 可选软件 | `/usr/local/bin` | 用户自编译程序 |

`/usr/local/bin` 就是"你自己装的东西"的默认家——将来把编译的 MPI、工具链装这里。

## 5. apt 还是 pip？（依赖管理的实战版）

没有绝对答案：系统管理器（apt）装全局、版本可能旧；语言管理器（pip）版本新、**有隔离**（virtualenv）。**铁律：别两边混装同一个包**——冲突起来极难调试。推荐：语言管理器 + 虚拟环境。

## 6. 性能分析的升级路线（模块 07 的深化）

**print 计时二分定位慢段 → line 级（Callgrind，慢 ~10 倍）→ 采样（perf）→ 火焰图可视化 → eBPF/bpftrace（内核/syscall 级）**。起步永远是 print+二分——先用最糙的工具确定"慢在哪个大段"，再上重武器。

## 7. 数据整理工具补全（模块 04 的延伸）

`jq`（JSON）、`pup`（HTML）、`column -t`（对齐空白文本）、pandas（表格数据的 groupby/join/绘图）、R+ggplot2（统计出图）。**Vim 宏处理重复多行编辑**（模块 03 的 C1 就是）。

## 8. Docker vs 虚拟机

VM 带完整内核整栈；**容器共享宿主内核**（Linux 隔离技术），开销低但隔离弱、且**要求同内核**（mac 上跑 Docker 其实内嵌了个 Linux VM）。容器默认**重启不保存储**——数据放 volume。

## 9. 发行版怎么选

日常差异极小，核心区别是**更新策略**：Arch 滚动更新激进 vs Debian/Ubuntu LTS 稳。推荐 Debian/Ubuntu（也是超算集群最常见环境——你 WSL 的 Debian 就是同款）。深入 OS 内部：MIT 6.828、Tanenbaum《现代操作系统》。

## 10. 其余速答

- **Vim vs Emacs**：都试；Emacs 装 Evil 可得模态编辑，扩展用 Lisp 写是优势
- **2FA**：密码之外的第二凭证；SMS 有已知弱点，推荐 **U2F 硬件钥匙**（YubiKey）
- **浏览器**：Firefox 是 Chrome 之外的好选择（隐私更佳）
- **ML 实验管理**：实验参数记进简单 JSON 文件——这样 shell 工具（jq/grep）就能筛选聚合你的实验记录（把模块 04 用到科研上）
- **Vim 进阶**：标记 `m<X>`/`'<X>`、`Ctrl-O/I` 跳转历史、`:earlier`/`:later` 时间旅行撤销、持久化 undo、leader 键、`cgn`（改下一个匹配并进入可重复状态）

## 11. 与超算比赛的联系

- FHS 表 + `module` 工具（集群上的环境管理，HelloHPC 第 2 题考过 `module load bisheng`）= 你在集群上找东西的地图
- "实验参数记 JSON + jq 聚合"：HPL 参数扫描的结果管理同款思路
- bash→Python 的边界感：赛题的自动化脚本一旦复杂，立刻换语言，别在 bash 里写算法
