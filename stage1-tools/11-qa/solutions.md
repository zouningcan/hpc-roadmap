# 模块 11 参考答案（stage1 结业考）

## A 卷速答

**A1** bash 层：`>` `<` `|` `&&` `||` `;` `*` `?` `{}` `$变量` `~`；程序层：收到纯参数列表（argv）。
**A2** 0 个：原样传字面量（碰巧对）；1 个：语义偷换、静默漏结果（最险）；≥2 个：`paths must precede expression` 报错。
**A3** `{` 是保留字（reserved word），必须独立成词；`{echo` 被解析成名叫 `{echo` 的命令。`}` 独占一行是防提前/意外闭合的格式纪律。
**A4** `ci(` = change inside 括号（删括号内并进插入）；`d$` = delete 到行尾；`3dw` = 计数 3 × 删词。
**A5** 锚定整行（`^...$`）+ 捕获组（`\1` 只留要的字段）。
**A6** 断网→SSH 断→sshd 发 SIGHUP→登录 bash 死→任务陪葬。tmux：任务挂在常驻的 tmux 服务器进程下，断线只杀客户端（取景器），attach 接回。
**A7** `./` 新开子进程跑（改副本，pass-by-value）；source 当前 shell 亲自执行（改本体，this 上调方法）。
**A8** reset 改写历史（像没发生过），revert 追加反向提交；**已推送到共享分支的提交绝对禁 reset**（只能 revert）。
**A9** 等待类瓶颈：IO/网络/锁（CPU 几乎没干活：user+sys 合计才 0.5s）。
**A10** 时间戳比较：目标比所有依赖新 → 跳过；依赖传递，改一处只重建下游。
**A11** 同步会传播删除/损坏/勒索，只防硬盘坏不防逻辑灾难。好备份：版本化、去重、可验证恢复（+异地）。
**A12** 66 bit 的四个词强得多——熵是可能性的对数，爆破时间随指数增长。

## B1

`wc -l` 对多文件输出**每文件一行 + 最后一行 total**，所以 `sort -nr | head -4` 取前三文件 + total 行（total 数字最大排最前）。若只要文件行可加 `| grep -v total`。第 1 步输出各模块 exercises.md 路径；第 2 步逐文件行数。
（体会：`xargs` 把 find 的输出变成 wc 的参数——模块 04/02 的知识在真实任务里自然组合。）

## B2

- `git fetch` 只更新 `origin/main` 等远端引用，不动工作区与本地分支——先侦察后行动
- `git branch -vv` 的 `[origin/main]` 表示该分支**绑定了上游**（upstream，push/pull 的默认目标）；`ahead 1` = 本地比远端多 1 个提交待推送；`behind N` = 远端有 N 个本地没有的提交

## B3

10000→50000（5 倍）：耗时应接近 **5 倍**（线性）——bash 算术循环是逐次 fork 内部机制的开销堆叠。Python 版通常快一个数量级以上（无逐次 shell 语义负担）。结论呼应官方 Q&A：**bash 的边界在"数字一大或逻辑一复杂"就现形**——循环算术这种活属于 Python。
（数字因机器而异，看数量级与线性关系即可。）
