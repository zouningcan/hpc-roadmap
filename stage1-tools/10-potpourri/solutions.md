# 模块 10 参考答案

## A1

守护进程 = **脱离终端、后台常驻**的系统进程。命名惯例以 **d 结尾**。例子：`sshd`（SSH 服务，等待连接）、`systemd`（1 号服务管理器）、tmux 的服务器进程（模块 05：你脱离后它还在跑——就是 daemon 的行为模式）。

## A2

同步和 RAID 的复制是**即时的、无版本的**：误删、文件损坏、勒索加密会被同样忠实地传播到所有副本/镜像盘。它们防的是**硬件故障**（盘坏），不防**逻辑灾难**（人为错误+攻击者）。真备份要：**版本化**（回到误删之前）、**去重**（版本多了才存得起）、**可验证恢复**（演练），并异地存放。

## A3

jq 是命令行 JSON 处理器：从 gh 返回的 JSON 对象里取出 `.login` 字段的值。"token 即身份"：API 不认"人"只认 token，持有者获得它的一切权限——所以要最小 scope、妥善保管、泄露立刻吊销（模块 09 案例回响）。

## A4

`rm -r` 是"递归删除"；`rm -- -r` 是"删除名叫 `-r` 的那个文件"——`--` 告诉程序"参数解析到此为止，后面全是普通文件名"。解决的是**文件名以 `-` 开头会被误认成 flag** 的问题（`touch -- -r` 同理创建）。

## A5

把**文件系统的实现**从内核搬到用户空间（FUSE = Filesystem in Userspace）。sshfs 挂载后，你对挂载点的 `cat file` 会：被 FUSE 截获 → 转成一条 SSH 请求发给远端 → 远端读取内容 → 经 SSH 送回 → 呈现给你。操作是本地的，数据在远端。

## B1

以实际输出为准。典型：`systemd`（服务管理器）、`sshd`（若有 openssh-server）、`dbus-daemon`（进程间通信总线）、`cron`（定时任务，虽不带 d 也是 daemon 性质）。要点：它们都不挂在你的终端上，`who` 看不到它们，却一直在服务。

## B2

- 前两条：`.login, .public_repos` 一次取两个字段（jq 的逗号 = 多输出）
- `.[0]` 只取数组**第一个**元素（一个 sha）；`.[]` **遍历全部**（每行一个）——head -3 截前三条。`.sha[0:7]` 是字符串切片：完整 sha 太长，取前 7 位（git 短哈希惯例，模块 06 见过）

## B3

裸 `ls` 会把 `-weird` 当 flag 报错（或与其他输出混淆）；`ls -- -weird` 正常列出。`rm -- -r` 精确删除名叫 `-r` 的文件——没有 `--` 时这条命令是灾难（递归删当前目录）。`touch -- -r` 创建时同理。

## B4

五字段：**分 时 日 月 周**（`* * * * *` = 每分钟）。理由：周期性任务用 cron 一行搞定、系统自管重试与日志；自己写 daemon 要处理后台化、日志、崩溃恢复、开机自启——复杂度与需求不匹配。

## C1

参考方案：本地 git 仓库（工作副本）+ 推送 GitHub（异地副本）+ 每日 `borg/restic` 版本化备份到外接盘（第二介质+版本化）。
"推 GitHub 只是其中一部分"：Git 远端是**当前状态的镜像**，`git push --force` 会直接**覆写**远端历史——误操作时 GitHub 上旧版本同样没了（除非有 PR/分支保护或依赖 GitHub 的 events 历史）。3-2-1 的"版本化+独立介质"仍需本地备份补足。

## C2

sshfs：`sshfs user@host:/path ~/mnt` 后，远端目录成为本地目录树的一部分，所有程序（编辑器、grep、find）都能直接用路径访问，**不发生整体拷贝**，按需读取；卸载 `fusermount -u`。与 scp/rsync 的区别：后者是**文件级拷贝**（先复制一份到本地），前者是**协议级挂载**（远程文件系统"长在"本地，访问即传输）。

## C3

status 关键行示例：
```
● hello.service - ...
   Active: active (running) since ...     ← 运行中
   CGroup: /system.slice/hello.service
           └─1234 /usr/bin/python3 -m http.server 8000    ← 实际进程
```
要点：daemon-reload 让 systemd 重读单元文件；ExecStart 用的命令必须写绝对/可解析路径；stop 后进程消失，disable 移除开机自启。
