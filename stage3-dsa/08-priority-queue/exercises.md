## A 概念题

**A1** 用无序向量/有序向量/堆三种实现各画一张"insert / getMax / delMax"复杂度表格，并用一句话说明堆为什么是三者的"最优折中"。
*考察点：ADT 实现谱系；log n 的由来。*

**A2** 将 `[4, 7, 2, 9, 5, 8]` 逐个 `insert` 建成大顶堆，画出最终数组；再用 Floyd 自下而上建堆法对同一序列建堆，画出数组。两个结果一样吗？各自的复杂度？
*考察点：两种建堆法；结果合法性 vs 唯一性。*

**A3** 大顶堆中，"找最小元素"复杂度是多少？最小元素可能在数组的哪些位置？
*考察点：堆序性只管父子——兄弟无序。*

**A4** 什么是 NPL？左式堆的"左倾"到底指什么？（说出不变量即可，不用证明）
*考察点：左式堆不变量；右脊路径 O(log n)。*

## B 动手题

**B1（手写堆，OJ 精神核心题）**：手写 `MaxHeap`：`push(x)` / `top()` / `pop()`，底层 `vector<int>`，上滤/下滤实现。用主函数测试：依次 push 5,3,8,1,9,2，输出每次 top()；再连续 pop 输出出堆序列（应为 9 8 5 3 2 1）。
*考察点：上滤/下滤实现；父子下标互算。*

**B2（建堆计时）**：对 n = 1e5, 1e6, 1e7 随机数据，分别测"逐个 push 建堆"与"Floyd 建堆"的耗时（毫秒表），填表并解释比值趋势。
*考察点：O(n log n) vs O(n) 的实测感知。*

**B3（堆排序）**：在 B1 的堆上实现就地堆排 `heapSort(vector<int>&)`：建堆后 n-1 轮"交换堆顶与末位 + 缩小规模 + 下滤"。验证升序输出。
*考察点：delMax 与排序的一体两面；原地性。*

**B4（TopK 流式）**：数据流（模拟 `rand()`）源源不断，内存只许维护 K=100 大小的结构，随时能回答"当前前 100 大"。用**小顶堆**实现，100 万个数测一遍，回答：为什么是"小顶堆"而不是大顶堆？复杂度多少？
*考察点：堆方向的逆向思维；流式 TopK 范式。*

## C 挑战题

**C1（左式堆 merge）**：手写左式堆（节点含 `l, r, npl`），实现 `merge(H1, H2)` 递归版，并在此之上实现 `push`（merge 单节点）与 `pop`（merge 两子树）。构造两个堆合并，画出手画过程验证 NPL 不变量。
*考察点：可合并堆；右脊递归；NPL 修复。*

**C2（考试预演：事件驱动模拟）**：模拟 RopeNet 式碰撞系统雏形：N 个粒子各带"下次碰撞时刻 tᵢ"，用堆维护"下一个要处理的事件"。循环：pop 最近事件 → 推进时间 → 计算新事件 push 回堆。实现 1 万粒度简化版并统计处理事件数。
*考察点：堆作为"时间轴"的用法——事件驱动模拟范式。*
