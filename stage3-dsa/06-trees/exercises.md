# 模块 06（stage3）练习：树——二叉树 / BST / AVL

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。

## A 概念题

**A1** 迭代先序的循环骨架是什么（两个 while + 一个栈的分工）？为什么迭代中序"沿左链入栈"？
*考察点：访问+右压栈+左深钻；左链入栈保证弹出序=中序。*

**A2** 🕷 为什么先序+中序能唯一重构，先序+后序不能？举一个后序歧义的最小反例。
*考察点：中序切分左右；单孩子无左右信息。*

**A3** 平衡因子定义？AVL 的高度上界（那个 1.44 系数的结论）说明什么？
*考察点：h(lc)-h(rc)∈{-1,0,1}；最坏也只比 log₂ 松 44%。*

**A4** LL/LR/RL/RR 四种失衡各自需要单旋还是双旋？画出（或描述）LR 型双旋的两步。
*考察点：zig-zig/zag-zag 单旋、zig-zag 双旋；先旋孩子再旋自己。*

**A5** 3+4 重构的"一个公式管四种情形"是怎么做到的？它删掉了哪类代码？
*考察点：三节点四子树统一拼接；删掉方向 case 分析。*

**A6** 🕷 为什么 AVL 的删除可能引发 O(log n) 次连锁旋转，而插入最多一次？
*考察点：插入局部增高一次修复；删除后子树变矮、祖先可能连环失衡。*

## B 动手题

**B1（遍历四式全迭代）** 手写四个非递归遍历（先/中/后 + 层次），对随机 1 万节点 BST 验证：
1. 迭代先序 == 递归先序输出
2. 迭代中序为升序
3. 后序迭代 == 递归后序（🕷 这是最容易写错的一个——用"上次访问"标记法）
4. 层次 = 按深度分层的序列
*考察点：四式全落地 + 递归版当预言机。*

**B2（重构实验）** 实现 build(pre, in)：
1. 随机生成 5000 棵树（随机形状），取其先序+中序喂给 build，重建树的中序/先序与原树全等断言
2. 构造两个**先序+后序相同**但形状不同的单孩子树（如 `a←b` 与 `a→b`，先序都是 ab、后序都是 ba）——实证歧义
*考察点：重构算法 + 歧义的最小反例。*

**B3（BST 三板斧 + 后继版删除）** 实现 BST 的 search/insert/remove（双孩子用**直接后继**交换——`succ()`：右子树的最左者）：
1. 随机 10 万元素全部插入后中序升序
2. 删除 5 万后中序仍升序、规模正确
3. 🕷 顺序插入 1..10⁵ 后测树高（≈10⁵ 的退化链）与 search 最坏耗时——退化实感
*考察点：后继版删除（与 CS106B 左 max 镜像）；退化树现场。*

## C 挑战题

**C1（AVL 完整实现 + 3+4 重构版）** 实现 AVL 树（节点带 height，插入+删除都支持）：
1. 用 **connect34(a,b,c,T0,T1,T2,T3)** 统一函数实现所有再平衡（禁写 if LL/LR/RL/RR 分支）
2. 插入 10 万随机数、顺序数各一遍：树高分别为多少？（顺序插入的 AVL 高度 ≈ 1.44·log₂n 附近 vs 同规模 BST 的 10⁵）
3. 删除一半后验证中序仍升序、全部节点 bf 合法
4. 统计：顺序插入全过程中总共发生多少次旋转？
*考察点：3+4 统一式的工程落地；平衡的量化收益。*

**C2（中序后继的迭代器）** 实现 `succ(x)`：x 有右子树 → 右子树最左；否则**沿父链上溯到"第一个向右拐的祖先"**。用它实现中序迭代器（`begin/next/end`）——中序遍历 O(n) 总时间、每步均摊 O(1)。
*考察点：succ 两种情形；迭代器=可暂停的遍历（std::map::iterator 的原理）。*

**C3（树的重构进阶：后序+中序）** a) 证明后序+中序同样能唯一重构并实现；b) 层次+中序呢？（提示：层序首元素=根，中序切分后，层序剩余部分按"属于左/右子树"分成两段——能做，但复杂度如何？）
*考察点：重构可行性的判定框架——任何"能定位根 + 能切分左右"的序对都行。*
