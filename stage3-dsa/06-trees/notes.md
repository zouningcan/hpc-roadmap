## 0. 一句话定位

二叉树的**遍历是所有树算法的母题**；BST 给树装上"有序"；AVL 用**旋转**治 BST 的退化病。本章的功力点：递归转迭代、序列化重构、旋转的统一记法。

## 1. BinNode / BinTree 骨架

```cpp
template <typename T> struct BinNode {
    T data;
    BinNode<T>* parent; BinNode<T>* lc; BinNode<T>* rc;
    int height;                                   // AVL 要用
    int size();                                   // 子树规模
    BinNode<T>* insertAsLC(T e);                  // 作为左孩子插入
    BinNode<T>* succ();                           // 中序直接后继（迭代遍历的钥匙）
};
```

术语与性质：**真二叉树**（节点度数 0 或 2）、**满二叉树**（每层全满，共 2^h−1 节点）、**完全二叉树**（层序无洞——堆的形状，stage2 模块 10）、深度/高度/叶数 = 度数 2 节点数 + 1。

## 2. 遍历四式：递归版与迭代版

递归版（stage2 已熟）：先/中/后序 = 访问语句在三行递归中的位置。邓课增量是**迭代版**——不爆栈、可中断、可并行（HPC 关心）：

### 迭代先序（一路向左 + 右孩子入栈）

```cpp
// 访问 x → 右孩子压栈 → 沿左链深入；到头弹栈回到最近的右子树
template <typename T, typename VST>
void travPre_I(BinNode<T>* x, VST& visit) {
    std::stack<BinNode<T>*> s;
    while (true) {
        while (x) { visit(x->data); if (x->rc) s.push(x->rc); x = x->lc; }
        if (s.empty()) break;
        x = s.top(); s.pop();
    }
}
```

### 迭代中序（左链入栈 + 后继定位）

```cpp
// 沿左链全部入栈 → 弹出访问 → 转向右子树重复
template <typename T, typename VST>
void travIn_I(BinNode<T>* x, VST& visit) {
    std::stack<BinNode<T>*> s;
    while (true) {
        while (x) { s.push(x); x = x->lc; }
        if (s.empty()) break;
        x = s.top(); s.pop(); visit(x->data);
        x = x->rc;
    }
}
```

### 迭代后序（反转思维）与层次遍历

后序迭代是三版中最绕的（需记录"上一次访问的节点"防右子树重复）——考频高；层次遍历用**队列**（BFS 同构）。

**为什么要会迭代版**：① 递归深度 = 树高，平衡树安全但**退化树爆栈**（模块 11/06 的老梗）；② 迭代版可**暂停/恢复**——迭代器语义；③ 森林/外存树超递归深度。

## 3. 先序 + 中序重构二叉树（经典必考）

- **先序首元素 = 根**；在中序里找到根的位置，**左边全是左子树、右边全是右子树**——递归重构两段
- 先序+后序**不能**唯一重构真二叉树以外的树（单孩子无法区分左右——想通这一点是作业）

```cpp
BinNode<char>* build(const char* pre, const char* in, int n) {
    if (n == 0) return nullptr;
    BinNode<char>* r = new BinNode<char>{pre[0]};
    int k = 0; while (in[k] != pre[0]) k++;              // 根在中序中的位置
    r->lc = build(pre + 1, in, k);                       // 左子树 k 个
    r->rc = build(pre + k + 1, in + k + 1, n - k - 1);   // 右子树 n-k-1 个
    return r;
}
```

## 4. BST：有序树上二分

查找 = 每层比较一次走一边（O(h)）；插入 = 查找失败处挂新叶；删除三案例（叶剪/单孩顶/双孩找**直接后继**交换后删除——邓课用后继，CS106B 用左子树 max，**镜像策略**）。

关键结论复刻：**中序遍历 = 升序**；最坏 O(n)（退化链）；**期望高度 ~O(log n)**（随机插入的平均情形）。

## 5. AVL：旋转的科学与艺术

**平衡因子** `bf(x) = height(lc) - height(rc) ∈ {-1, 0, +1}`——AVL 树要求**每个节点**满足。插入/删除可能破坏（bf 变 ±2），在**最低失衡节点**处旋转修复：

### 四种失衡 → 两种旋转

| 失衡型（LL/LR/RL/RR） | 修复 |
|---|---|
| LL（左孩子的左侧插入） | **zig-zig**：单旋（右旋） |
| RR | **zag-zag**：单旋（左旋） |
| LR | **zig-zag**：双旋（先左旋左孩子，再右旋） |
| RL | **zag-zig**：双旋 |

### 3+4 重构：四种情形一个公式

四种旋转本质都是"**三个节点 a<b<c 与四棵子树 T0<T1<T2<T3 重新拼接**"：

```
        b
      /   \
     a     c
    / \   / \
   T0 T1 T2 T3
```

**不管原来怎么歪，拼成这个形状**——zig/zag 的方向判断全部消失，一段代码处理四种失衡（邓课的工程美学名场面）。旋转后**只有 O(1) 高度更新**（受影响节点 ≤ 3 个）。

### AVL 性能账

- 高度 ≤ 1.44·log₂(n+2)（斐波那契界的著名结论）：**保证 O(log n)**
- 插入：至多一次旋转修复；删除：可能 **O(log n) 次连锁旋转**
- 旋转是**局部操作**（改 3 指针 + 高度）——适合并发/持久化；代价是每节点存 height

## 6. 常见误区清单

1. 迭代中序忘"弹出后转右子树"——死循环在叶子
2. 迭代后序的"回来自右孩子"判断漏写——重复访问右子树
3. 先序+后序当能唯一重构——单孩子树有歧义
4. AVL 只在最低失衡点转一次就收工——**删除可能向上连锁失衡**
5. 旋转后忘更新 height（自底向上回溯）——后续平衡判断全错
6. 平衡因子只查插入路径上的一个点——AVL 要求**每节点**都合法

## 7. 与超算比赛的联系

- **迭代遍历 = 任务队列化**：树的迭代先序（栈驱动）天然映射为并行任务流（stage4 OpenMP task 的递归分治是它的反面——递归版在并行运行时反而方便，两种形态都要会）
- **先序+中序重构 = 序列化/反序列化**：树的传输格式——分布式构建空间剖分树（BSP/kd-tree）的基础操作
- **3+4 重构的"统一式"思想**：把 case 分析压缩成不变式——大型 HPC 代码减少分支 = 减少 bug 面（与哨兵消除特例同族）
- AVL/红黑树等平衡结构是 std::map 底座（stage2 已揭），比赛里手写平衡树的场景集中在**动态有序维护**（如离线维护排名）
