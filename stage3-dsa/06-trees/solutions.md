# 模块 06（stage3）参考答案

## A1

迭代先序：外层循环轮次 = "一棵子树"；内层沿左链深入——**访问当前节点、右孩子压栈、走向左孩子**；左链尽则弹栈接管最近的右子树。迭代中序"沿左链入栈"：中序要求左→根→右，左链入栈后**弹出的顺序恰好是自底向上的左链**，弹出即访问，然后转向右子树——"入栈攒左链，弹出访中，转右再来"。

## A2

先序首元素锁定**根**，中序中根的位置**切分左右子树**（左右各归其位），递归可得唯一树。先序+后序：根在两端都能拿到，但**无法知道单孩子挂在左边还是右边**。最小反例：`a-b` 两个节点，b 作 a 的左孩子或右孩子，先序都是 `ab`、后序都是 `ba`——两种形状同序对，歧义实证。

## A3

bf(x) = height(lc) − height(rc)，AVL 要求所有节点 bf ∈ {−1, 0, +1}。高度上界 1.44·log₂(n+2)（斐波那契树是最坏形状）：**AVL 最坏也只比理想 log₂ 松 44%**——"平衡"是渐近保证，不是完美二分。

## A4

LL（左左）与 RR：**单旋**（zig-zig 右旋 / zag-zag 左旋）；LR 与 RL：**双旋**。LR 双旋：x 的左孩子 g 先**左旋**（zag，把孙节点提上来）变成 LL 型，再对 x **右旋**（zig）——两步后孙节点成为新的局部根。RL 镜像。

## A5

观察到四种失衡修复后的**最终形态唯一**：三个节点按大小 a<b<c 作顶，四棵子树 T0<T1<T2<T3 按中序位置挂好——connect34 一次性拼出该形态。它删掉的是**方向判断与镜像复制的 case 分支**（LL/LR/RL/RR 四段代码合一）：分支越少，测试面与 bug 面越小。

## A6

插入：新节点使某祖先失衡，一次旋转后该子树高度**恢复到插入前**——上层祖先不再受影响，修复至多一次。删除：旋转后子树可能**比删除前更矮**，父节点可能因此新失衡——逐层向上可能连环旋转，最坏 O(log n) 次（每次 O(1)，总仍 O(log n)）。

## B1 参考

后序迭代（标记法）：
```cpp
while (!s.empty()) {
    x = s.top();
    if (x->rc == last || x->lc == last || (last 是刚访问的孩子)) {
        visit(x); last = x; s.pop();               // 孩子处理完了，轮到自己
    } else if (x->rc) s.push(x->rc);               // 先压右
    else if (x->lc) s.push(x->lc);                 // 再压左
    ...
}
```
验证策略：递归版输出存文件做 diff——**每写一个迭代版立即对拍**。

## B2 参考

build 见讲义第 3 节；验证：重建树再跑先序/中序与原序列断言相等（5000 棵循环）。歧义反例：`a` 的左孩子 `b` 与右孩子 `b`——pre=`ab`、post=`ba` 全同，形状不同。

## B3 参考

后继版删除：双孩子时找 `succ(x)`（右子树一路向左），**交换数据**，删除后继节点（它至多一个右孩子——退化为单孩/叶案例）。顺序插入 1..10⁵：树高 = 10⁵−1（纯链），search(10⁵) 需 10⁵ 次比较（毫秒级但已是线性）；对照随机插入树高 ~2·log₂(10⁵)≈34。

## C1 参考

connect34：
```cpp
BinNode<T>* connect34(BinNode<T>* a, BinNode<T>* b, BinNode<T>* c,
                      BinNode<T>* T0, BinNode<T>* T1, BinNode<T>* T2, BinNode<T>* T3) {
    a->lc = T0; a->rc = T1; if (T0) T0->parent = a; if (T1) T1->parent = a;
    c->lc = T2; c->rc = T3; if (T2) T2->parent = c; if (T3) T3->parent = c;
    b->lc = a; b->rc = c; a->parent = b; c->parent = b;
    a->height = 1 + max(h(a->lc), h(a->rc));   // 自底向上更新三个
    c->height = 1 + max(h(c->lc), h(c->rc));
    b->height = 1 + max(a->height, c->height);
    return b;
}
// 调用处按 bf 方向选出 a<b<c 与 T0..T3 的对应（一次比较定序，无四路分支）
```
实测：10 万随机 → 高 ~20+；10 万顺序 → 高 ~25 以内（1.44·log₂(10⁵) ≈ 24）vs BST 的 10⁵；顺序插入全程旋转数千次（每次插入 O(1) 次）。

## C2 参考

```cpp
BinNode<T>* succ(BinNode<T>* x) {
    if (x->rc) { x = x->rc; while (x->lc) x = x->lc; return x; }
    while (x->parent && x == x->parent->rc) x = x->parent;   // 我是右孩子就一直上溯
    return x->parent;                                        // 第一个"我是左孩子"的父亲
}
```
迭代器 next() = succ——n 次 next 总步数 O(n)（每条边至多被上溯/下钻各一次）→ **均摊 O(1)**。这就是 std::map 迭代器的工作原理。

## C3 参考

a) 后序**末元素=根**，中序切分左右——与先序版对称，可行（实现同 build，根取 post[n-1]，段切分注意后序左右子树段连续）。
b) 层次+中序**可行但代价高**：层序首元素=根；中序切分出左右子树**元素集合**后，需把层序序列**按集合归属拆成两段**（保序过滤）——每层 O(n) 过滤、共 O(h) 层，总 O(n·h)（平衡树 O(n log n)，退化树 O(n²)）。判定框架：**序对可行 ⟺ 根可定位且左右子树可切分**（先/后/层序给根，中序给切分；缺中序则单孩子歧义）。
