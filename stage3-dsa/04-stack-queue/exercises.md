# 模块 04（stage3）练习：栈与队列

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。手写循环队列与栈（不用 STL）。

## A 概念题

**A1** 循环队列如何判空与判满？"lo/hi 真值单调递增、访存才取模"避开什么坑？
*考察点：留一格空或计数器；避免回绕后的次序混乱。*

**A2** 🕷 n=3 的 5 种合法栈混洗之外，哪个序列不合法、为什么（用 312 禁形解释）？总数公式是？
*考察点：312 不合法；Catalan 数。*

**A3** 除基取余为什么配栈（或递归）？余数的产出序与需要的输出序差在哪？
*考察点：低位先出=倒序；栈的 LIFO 天然正序化。*

**A4** 双栈中缀求值里，新运算符与栈顶运算符"相等优先级"时为什么弹栈计算而不是入栈？（提示：左结合）
*考察点：a-b-c 应算成 (a-b)-c——左结合要求同级弹。*

**A5** 栈混洗的"正解判定"为什么是 O(n) 模拟而不是查 312 禁形？
*考察点：模拟一遍=贪心压弹；312 判定朴素 O(n³) 且实现易错。*

## B 动手题

**B1（循环队列 RingQueue）** 手写环形队列（初始容量 8、满 7 时倍扩）：
1. enqueue 20 个、dequeue 10 个、再 enqueue 10 个——全程正确（打日志验证环绕）
2. 🕷 造一次回绕 bug：若 `hi` 在入队时直接 `hi = (hi+1)%M`，什么场景下 `size()` 会算错？
*考察点：真值单调 vs 存储取模两套坐标的正确分离。*

**B2（栈混洗判定器）** 实现 `bool isPermutation(const int target[], int n)`：输入 `<1..n>` 依序进栈，模拟能否产出 target：
```
next=1; 对 target 每个元素 e：while (stack空或栈顶≠e) 压入 next++;
      若栈顶==e 弹出继续；否则中途压完仍不符 → 不合法
```
测试：123/132/213/231/321（合法）与 **312**（不合法）；n=6 全排列枚举，合法数 = Catalan(6)=132？
*考察点：O(n) 贪心模拟；Catalan 计数的程序验证。*

**B3（双栈中缀求值）** 实现完整版（支持 + - * / ( ) 与一位数字）：
1. 优先级表驱动（含 `\0` 哨兵）
2. 测试：`(1+2)*3`=9、`8-3-2`=3（🕷 不是 7——验证左结合）、`6/2/3`=1、`2*(3+(4-1))`=10
3. 输出每步双栈快照（考察追踪能力）
*考察点：双栈算法完整落地；左结合的正确处理。*

**B4（进制转换双版）** 递归版与显式栈版各实现 convert(n, 16)，对 300 输出 `12C`。两版的栈帧/栈容器对应关系画出来。
*考察点：递归=隐式栈的再证。*

## C 挑战题

**C1（中缀→逆波兰 shunting-yard）** 把双栈求值改造为**转换器**：输出 RPN 而不是直接算值。用生成的 RPN 喂给 stage2 的后缀求值器，对 20 个随机表达式断言两路结果一致（**交叉验证**）。
*考察点：Dijkstra shunting-yard——编译器/Excel 公式引擎的直系祖先；性质测试。*

**C2（双栈排序——经典面试）** 一个栈 + 一个辅助栈，把栈内元素从顶到底升序排列（只许 push/pop/peek）。描述你的策略（找最小、倒腾、归位），实现并测试。
*考察点：栈上模拟随机访问的技巧——对受限结构的深度理解。*

**C3（火车调度问题——栈混洗的工程皮肤）** n 节车厢编号 1..n 依序驶入单向栈形轨道，问能否按给定目标序驶出（就是栈混洗），输出 `Yes/No`；再加一问：**至多再用一条辅助轨道**（两栈并联）时哪些新序列变得可行（试 n=3：312 单栈不行，双栈呢？）
*考察点：抽象能力——把应用题还原为栈混洗；栈数量的组合爆炸直觉（双栈混洗判定已是 NP 完全——指数世界离得不远）。*
