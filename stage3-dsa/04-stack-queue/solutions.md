# 模块 04（stage3）参考答案

## A1

空：`lo == hi`；满：`(hi - lo) == _capacity - 1`（留一格）或独立计数器判满。"真值单调递增"避开的坑：若 lo/hi 本身取模回绕，`(hi - lo)` 可能**负数**、大小比较方向反转——把"序"交给真值、把"位置"交给取模，两套坐标永不打架。

## A2

不合法的是 **312**。312 禁形：输出中出现 i<j<k 但顺序呈 k,i,j（即 3,1,2 型）时无解——因为 3 要先出栈则 1、2 已在栈内且 2 压着 1，之后只能先 2 后 1，不可能 1 在 2 前。总数 = Catalan 数 **C(2n,n)/(n+1)**（n=3 时 5，n=6 时 132）。

## A3

余数从**低位到高位**产出（先算出的是个位），而正确输出需要高位在前——产出序与需求序正好相反；栈 LIFO 反转序列（或递归"钻到底再吐"）天然修正。

## A4

因为中缀四则运算**左结合**：`8-3-2` 必须 (8-3)-2=3。若同级入栈不弹，后面算成 8-(3-2)=7。同级弹栈 = 先算左边的——右结合运算符（如幂 `^`）则相反：同级应入栈不弹。

## A5

312 禁形是**数学刻画**（判定的"为什么"）；工程判定用 O(n) 贪心模拟：对目标序列逐个元素，把还没进栈的数依次压到栈顶等于它为止、弹出——若 next 已超 n 仍不匹配则不合法。模拟本身就是证明的构造过程。

## B1 参考

```cpp
void enqueue(T e) {
    Q[hi % _capacity] = e; hi++;                 // 真值递增
    if (hi - lo == _capacity) expand();          // 满（含扩容）
}
```
回绕 bug：若 `hi = (hi+1) % M` 且无独立 size，队列从满到再入队时 hi 回卷到 lo 附近，`size = (hi-lo+M)%M` 算对但 `lo<=hi` 的直觉全灭，扩容迁移元素的下标推导变成灾难——**真值版一个 for 拷完**。

## B2 参考

```cpp
bool isPermutation(const int target[], int n) {
    std::vector<int> st; int next = 1;
    for (int i = 0; i < n; i++) {
        while (st.empty() || st.back() != target[i]) {
            if (next > n) return false;
            st.push_back(next++);
        }
        st.pop_back();
    }
    return true;
}
```
枚举 n=6 全排列：合法 132 个 = Catalan(6) ✓。312 的失败点：目标 1 时 next 已耗尽（3 出栈前 1、2 已压且 2 在上）。

## B3 参考

双栈核心循环（optr 底垫 `'\0'` 哨兵）：
```cpp
for 每个token：
    数字 → opnd.push(值)
    '(' → optr.push
    ')' → while (top!='(') calc(); pop '('
    运算符 op → while (prio(top) >= prio(op) && top!='(') calc();  // >= 即左结合
                optr.push(op)
结束：while (optr.size()>1) calc();
```
`8-3-2`：第二个 `-` 入栈前发现栈顶 `-` 同级 → 先算 8-3=5 → 再算 5-2=3 ✓（< 则得 7 ✗）。

## B4 参考

递归版每层调用的"返回后打印"= 显式栈版的"全部压完再弹出打印"——栈帧与栈容器一一对应（调用栈就是那个栈）。

## C1 参考

shunting-yard：把"弹栈计算"改成"弹栈**输出**到 RPN 队列"，数字直接输出；扫描完弹空栈。交叉验证：随机表达式（合法括号）生成器 + 双路求值 + 断言相等——**两个独立实现的相互印证**是编译器前端的经典测试法。

## C2 参考

策略：辅助栈当"已排序区"。主栈顶弹出当前段最小值的过程：主栈倒到辅助栈找最小（记位置），倒回来时把最小压入辅助栈已排序段……更简明的循环版：
```
while 主栈非空：
    t = 主栈.pop()
    while 辅助栈非空 且 辅助栈顶 > t：辅助栈弹回主栈
    辅助栈.push(t)
```
辅助栈从顶到底升序；总复杂度 O(n²)（最坏），均摊远好。要点：**辅助栈顶永远维护"当前待放元素的正确落点"**。

## C3 参考

单栈 = 栈混洗判定（B2 直接复用）：312 输出 No。双栈并联：3 可以入栈 A，1 入栈 B，出 3、1、2（2 在 A 中 3 之下，3 出后即可出）——**312 变得可行**。深挖：n 元素 k 栈混洗的判定，k≥2 时是 **NP 完全**——一条辅助轨道就把问题从"线性可判"扔进"指数地狱"，这个悬崖在并行调度、指令发射的工程世界里真实存在。
