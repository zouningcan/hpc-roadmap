## 0. 一句话定位

两种受限线性表（栈=LIFO、队列=FIFO），受限即语义。本章三宝：**栈混洗计数与判定（组合数学）、表达式求值（编译器前端的骨架）、循环队列（取模艺术）**。

## 1. 实现选型

- **栈**：向量即可（尾部进出 O(1)）——`push/pop/top`；列表版头插头删同理
- **队列**：**循环数组**——`Q[lo % M]`，lo/hi 双指针只进不退、下标取模环绕；空满判定留一格空位（`(hi+1) % M == lo` 为满）——比链表版少一次 new

```cpp
template <typename T> class Queue {
    T* Q; int _capacity, lo = 0, hi = 0;      // [lo, hi) 环形区间
public:
    void enqueue(T e) { Q[hi++ % _capacity] = e; if (size() == _capacity) expand(); }
    T dequeue() { return Q[lo++ % _capacity]; }
    int size() { return hi - lo; }
};
```

环形的本质：**lo/hi 单调递增做"真值"（永不回绕），取模只发生在访存时**——避开"回绕时谁先谁后"的判断泥潭。

## 2. 栈的应用四连

### 2.1 进制转换（递归的栈本质）

```cpp
void convert(int n, int base) {        // 逆序产出 → 栈正序收集
    if (n == 0) return;
    convert(n / base, base);
    putchar("0123456789ABCDEF"[n % base]);
}
```
除基取余的余数**逆序**排列——递归"钻到底再吐出"天然倒序（printStringReverse 同构）。

### 2.2 括号匹配（消去法）

扫描：左括号压栈；右括号弹栈配对；终了栈空即匹配——**可消对的序列 ⟺ 栈空且无欠账**（stage2 C1 的同款，O(n)）。

### 2.3 🕷 栈混洗（stack permutation）——本章的组合数学招牌

输入 `<1,2,...,n>` 依序进栈（可随时出栈），问哪些输出序列是合法的混洗？

- n=3 共 5 种合法（`123 132 213 231 321`）——**总数 = Catalan 数 C(n) = C(2n,n)/(n+1)**（指数级 ~4ⁿ/n^1.5）
- **312 禁形定理**：`<3,1,2>` 型（任意三个位置 i<j<k，输出呈 k,i,j 次序）**当且仅当**序列含 312 模式时**不是**合法混洗——判定 O(n³) 朴素、O(n) 精巧（栈模拟一遍即可）

**判定正解**：直接用栈模拟目标序列（贪心压栈到所需元素、能弹则弹）——能完整弹出即合法，O(n)。

### 2.4 表达式求值：中缀 → 逆波兰 → 双栈

- **中缀** `(1+2)*3`：人读的，机器难办（优先级+括号+结合性）
- **逆波兰 RPN** `1 2 + 3 *`：无歧义、单栈可算（stage2 已做求值器）
- **中缀直接求值（双栈算法）**——编译器前端的活化石：

```
opnd 栈（操作数）+ optr 栈（运算符）
扫描中缀式：
  数字 → opnd
  运算符 → 与 optr 栈顶比优先级：
     栈顶更高/相等 → 弹两个数一个符、算完压回 opnd，再比
     栈顶更低 → 新符入栈
  '(' 入栈；')' 一路弹到 '('
```

**优先级矩阵**是算法的心脏（含 `\0` 哨兵垫底——哨兵思想第三次出场）。

## 3. 队列的应用：BFS 与轮转调度

- **BFS** 的 frontier 层级扩张（stage2 模块 14 的队列驱动）
- **轮转调度（round-robin）**：CPU 时间片轮转 = 进程队列转圈——"尾插头取"的天然模型

## 4. 常见误区清单

1. 循环队列判空满用同一条件（`lo==hi`）——留一格空位或计数器二选一
2. 循环下标先取模再比较大小——应**比较"真值" hi-lo，只在访存时取模**
3. 栈混洗判定用"猜"——312 禁形可判，但 O(n) 模拟才是工程答案
4. 双栈求值弹栈顺序搞反（先弹的是右操作数——stage2 后缀求值同坑）
5. 递归实现忘了基例（进制转换 n==0）——无限递归

## 5. 与超算比赛的联系

- **栈混洗 = 任务依赖可行性判定**：给定目标输出序（如指令重排、访存序），能否由栈式缓冲达成——处理器乱序发射的罗塞塔石碑
- 双栈求值 = **配置文件解析器**的原型：WRF 的 namelist、Slurm 脚本参数的解析同构（状态+栈）
- 循环队列的取模环形 = **环形缓冲区（ring buffer）**：MPI 流水线通信、GPU 帧队列、perf 事件缓冲的公共底座——HPC 中出现率最高的数据结构之一
- Catalan 数视角：指数级状态空间 → 判定用多项式算法——**组合爆炸与可行判定的分野**正是优化赛题的本质
