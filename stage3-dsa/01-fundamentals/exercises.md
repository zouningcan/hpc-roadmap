## A 概念题

**A1** 算法的五大特性？"正确性"为什么强调"一切合法输入"而不是"我测过的输入"？
*考察点：输入输出/确定性/可行性/有穷性/正确性；测试≠证明。*

**A2** O、Ω、Θ 各表示什么？平时说"这算法是 O(n log n)"时我们实际想要的记号是哪个？
*考察点：上界/下界/紧界；Θ。*

**A3** 四大级数（算术/几何/调和/Σlog i）各自的求和结果？各举一个数据结构场景。
*考察点：Θ(n²)/Θ(n)/Θ(log n)/Θ(n log n)；选择排序/扩容摊还/哈希平均/插入建堆。*

**A4** a) 减而治之与分而治之的区别（削多少、递归树形状）？b) 线性递归求和与二分递归求和都是 O(n)，差别在哪一项？
*考察点：削1 vs 对半；递归深度 O(n) vs O(log n)。*

**A5** 🕷 朴素 fib 慢的真正原因是什么？"记忆化"为什么把它降到 O(n)？
*考察点：重叠子问题指数爆炸；查表防重复。*

**A6** 尾递归是什么？为什么不能指望编译器优化它？
*考察点：返回值=递归调用返回值；C++ 不保证 TCO，手写迭代。*

## B 动手题

**B1（求和三版）** 不用 STL，实现数组求和三版并各数**递归深度**（全局计数器）：
1. 迭代版
2. 线性递归版（减治）
3. 二分递归版（分治）
对 n = 10⁶ 各测递归深度与耗时（迭代版深度 0）。二分版深度应约 log₂(10⁶) ≈ 20——和 O(n) 深度的线性版差多少？
*考察点：两种递归的深度差异用数字显形；顺带体验 10⁶ 深度会不会爆栈（8MB 栈、每帧几十字节）。*

**B2（fib 三部曲 + 调用计数）**：
```cpp
long long calls = 0;
long long fibRec(int n) { calls++; /* 朴素版 */ }
long long fibMemo(int n);   // 记忆化（数组当表）
long long fibIter(int n);   // 滚动变量
```
1. fibRec(35) 的 calls 是多少？和 fib(35) 本身什么比例关系？
2. fibMemo(90)、fibIter(90) 各多少 calls？
3. fibRec(50) 别跑——按 1 的规律估算要多久？
*考察点：调用次数的爆炸规律（≈2×fib(n)）；90 用 long long 防 int 溢出（fib(93) 是 int64 极限附近）。*

**B3（调和级数实证）**：
```cpp
double h = 0;
for (int i = 1; i <= n; i++) h += 1.0 / i;
```
对 n = 10³、10⁶、10⁹ 输出 h。验证 h ≈ ln(n) + 0.577（欧拉常数）——n 每乘 1000，h 才涨多少？"调和级数 = Θ(log n)"的手感。
*考察点：对数增长到底多慢——1 到 10 亿只涨 ~21。*

**B4（🕷 大 O 速判）** 纸笔化简并排序（阶由高到低）：
```
n³/100、2ⁿ/1000、n·log n、100·n²、log³n、n^(0.5)、调和级数、几何级数求和 n
```
*考察点：丢系数取最高阶；对数多项式 log³n 仍低于任何 n^ε。*

## C 挑战题

**C1（快速幂：分治的第一次实战）** 不用 pow()，计算 xⁿ mod m（n 可达 10¹⁸）：
- 朴素连乘 O(n) 会死；分治：xⁿ = (x^(n/2))² × (n 奇则补 x)
- 实现 + 递归方程 T(n)=T(n/2)+O(1) → **O(log n)**
- 测试：2^10^18 mod 1e9+7 秒出
为什么说它是"减而治之的对半版"？
*考察点：指数减半；RSA 加密的基石运算——HPC 大数运算同款。*

**C2（LCS 初见：DP 第二课）** 两字符串最长公共子序列（递归定义）：
```
lcs(i,j) = -1 + lcs(i+1, j+1)                 当 s[i]==t[j]
         = max(lcs(i+1,j), lcs(i,j+1))        否则
```
1. 朴素递归对 20 字符串要多少次调用（实测计数）？
2. 加二维表记忆化后呢？
3. （选做）改成自底向上二维数组迭代
*考察点：二维重叠子问题；fib 到 LCS 是 DP 从一维到二维的自然延伸。*

**C3（模型思考题）** RAM 模型假设"每次访存 O(1)"。用模块 02 的行优先/列优先实验数据反驳它，并回答：既然假设是错的，为什么复杂度分析还有用？（提示：分析的输出是**阶级**；阶级内部的高低由什么决定——这正是超算比赛做的事）
*考察点：理论模型的适用边界；"选对阶级（Big-O）+磨常数（缓存/向量化）"的两层分工。*
