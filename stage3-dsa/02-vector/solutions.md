# 模块 02（stage3）参考答案

## A1

递增：总搬移 1+2+…+n/I → **算术级数 Θ(n²)**，摊还每次 Θ(n)；倍增：1+2+4+…+n < 2n → **几何级数 Θ(n)**，摊还 **O(1)**。倍增代价：容量最高达 2×_size，装填因子最低 50%——约一倍空间冗余。

## A2

a) insert：r 及之后全体后移一格 + 写入 = O(_size - r + 1)，最坏 O(n)。
b) 区间删除把"删 k 个 = k 次 O(n)"合并为**一次前移 _size-hi 个元素**；逐个删时每次删除后所有后续元素都要搬，总 O(k·n)。

## A3

deduplicate：**无序**前提，对每个元素在前缀里 O(n) 查重、重复则 O(n) 删除 → O(n²)。uniquify：**有序**前提（相同必相邻），双指针 O(n)。i = **已去重区的末尾**（[0,i] 无重复且保序）；j = **探测指针**——A[j]≠A[i] 时它是新元素，前移到 ++i；相等则跳过。

## A4

A 每轮最多**两次**比较（`e<A[mi]`、`A[mi]<e`）；B 每轮**一次**（二分支，命中延迟到循环外验证）。C 返回**不大于 e 的最后一个元素的秩**（全体 < e 则 lo-1）——它正好是"保持有序的插入位"，`insert(search(e)+1, e)` 永远正确，插入代码零特例。

## A5

让"浅的那一侧"（少比较次数）承担**更多**的查找份额：切分点按黄金分割（≈0.382:0.618），左边浅而多访、右边深而少访——**不均衡的树形换来均衡的平均代价**。

## A6

若 50% 就缩、100% 就扩，临界负载会在两个状态间**抖动**（一次插入一次删除就触发一轮 O(n) 搬家）；25% 阈值留出**滞后带**（25%~100% 之间静默），抖动不可能连续发生。

## B1 参考

关键实现提示：
```cpp
template <typename T> void Vector<T>::expand() {
    if (_size < _capacity) return;
    _capacity = std::max(_capacity << 1, 4);          // 倍增（且不小于初始 4）
    T* old = _elem; _elem = new T[_capacity];
    for (int i = 0; i < _size; i++) _elem[i] = old[i];
    delete[] old;
}
```
验收：mergeSort 与 bubbleSort 输出一致且 disordered()==0；100 万插入全程不炸（expand 至少触发 ~18 次）；uniquify 后相邻元素两两不等。

## B2 参考现象

| N | 递增总搬移 | 倍增总搬移 |
|---|-----------|-----------|
| 10⁴ | ~5×10⁵（≈N²/2I） | ~1.6×10⁴（<2N） |
| 10⁵ | ~5×10⁷ | ~1.7×10⁵ |
| 10⁶ | ~5×10⁹（分钟级耗时） | ~1.9×10⁶ |

比值随 N 线性拉大（~N/2I vs ~2）——算术 vs 几何级数的活体对照；10⁶ 时递增版可能慢到需要降 N 观察。

## B3 参考

1) 三版命中结果一致；2) 平均比较次数：A ≈ 2log₂n、B ≈ log₂n+1、C 与 B 同族（C 是 B 的语义化变体）；3) 版本 C 返回 r 满足 `A[r] ≤ e < A[r+1]`（严格讲 A[r] 是不大于 e 的最大者）；4) `orderedInsert`：`insert(search(e) + 1, e)` ——**零个 if**：语义已把"存在/不存在/边界"三种情形统一进返回值。

## C1 参考

```cpp
void rotate(int k) { reverse(0, k); reverse(k, _size); reverse(0, _size); }
```
正确性思路（不变量）：前 k 个**逆置**后在全局逆置时恰好落到尾部并恢复内部顺序——等价于"每段各自逆、再整体逆"。实测：逐个 insert 版在 n=10⁶、k=5×10⁵ 下分钟级；三翻转毫秒级。应用：矩阵分块旋转、SIMD 数据重排、字符串轮转匹配的同款内核。

## C2 参考

自后向前 = 返回**最后出现者**：deduplicate 里"删掉后面的重复者、保留最早副本"——保**首次插入序**；改成最先出现则保留末次。语义无对错，但**必须与调用方预期一致**——这是接口设计的第一课（对照 std::remove/unique 语义之争）。

## C3 参考

```cpp
Vector(const Vector& v) { copyFrom(v._elem, 0, v._size); }
Vector& operator=(const Vector& v) {
    if (this != &v) { delete[] _elem; copyFrom(v._elem, 0, v._size); }
    return *this;
}
```
不加：默认拷贝**浅拷贝**——两对象的 _elem 指向同一数组，析构时**double-free**（ASan 报 heap-use-after-free/double-free），且一方改动污染另一方。Rule of Three：**析构、拷贝构造、赋值三者要么都手写、要么都默认**——拥有裸资源的类没有中间路线（unique_ptr 版可整体免役，见 stage2 模块 09 C1）。
