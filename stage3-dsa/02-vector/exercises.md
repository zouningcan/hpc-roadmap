## A 概念题

**A1** 递增 vs 倍增扩容：各自的"总搬移次数"用哪个级数刻画？摊还各是多少？倍增付出什么空间代价？
*考察点：算术 Θ(n²)/几何 Θ(n)；O(n) vs O(1)；装填因子最低 50%。*

**A2** a) `insert(r, e)` 的代价构成？b) 为什么**区间** remove(lo,hi) 远优于逐个 remove？
*考察点：后移一格 O(n)；逐个删每个 O(n)，区间删一趟搬完。*

**A3** 🕷 deduplicate 与 uniquify 各自的前提与复杂度？uniquify 双指针的"i 与 j 各自代表什么"？
*考察点：无序 O(n²) 查前缀 vs 有序 O(n) 相邻；i=已整理区末、j=探测指针。*

**A4** 二分查找版本 A 与 B 各自每轮比较几次？版本 C 的返回值语义是什么、为什么这个语义让 insert 无需特例？
*考察点：A 两次 B 一次；C 返回不大于 e 的最后秩 = 插入位。*

**A5** Fibonacci 查找改进的是"平均成功查找代价"，它靠什么不均衡达到均衡？
*考察点：切分点按黄金分割，浅的左边多承担。*

**A6** shrink 为什么用 25% 阈值而不是 50%？
*考察点：滞后带防增缩抖动。*

## B 动手题

**B1（手写 Vector<T> 全家桶）** 按讲义骨架实现：`copyFrom / expand / shrink / operator[] / insert / remove(lo,hi) / find / deduplicate / disordered / uniquify / search(版本C) / bubbleSort / mergeSort`。
测试矩阵：
1. 随机 1 万元素：bubbleSort 与 mergeSort 结果一致且有序（`disordered()==0`）
2. 插入 100 万个随机数不炸（扩容路径被真实踩过）
3. 有序向量 uniquify 后无相邻重复
*考察点：邓课 OJ 式的完整实现能力；用 disordered 做自动验收。*

**B2（🕷 扩容策略大对决——级数显形）** 给 Vector 加两个策略开关：`+100`（递增）与 `×2`（倍增），并统计**元素总搬移次数**：
对 N = 10⁴、10⁵、10⁶ 各测两种策略的搬移总数与总耗时。比值随 N 怎么变？与 Θ(n²)/Θ(n) 的预测吻合吗？
*考察点：把级数工具箱的判决亲手跑出来——几何 vs 算术的直观差距。*

**B3（二分三版本对比）** 实现版本 A（三分支）、B（二分支）、C（插入位语义）：
1. 正确性：1 万元有序数组上，search 每个**存在的**值都能命中（三版一致）
2. **比较次数**：加计数器，随机查询 1 万次，三版平均比较次数各多少？
3. 语义实验：查找**不存在**的值，版本 C 返回的秩满足什么性质（A[秩] < e ≤ A[秩+1]）？
4. 用 C 的语义写 `orderedInsert(e)`（插入后仍有序）——代码里有几个 if？
*考察点：比较次数的实测差异；语义统一带来的代码简洁。*

## C 挑战题

**C1（逆置与轮转：三次翻转法）** 实现 `reverse(lo,hi)`（双指针对撞交换），再实现 `rotate(k)`（前 k 个元素整体移到尾部）：
- 法一：逐个 insert 到尾部（O(n·k)）
- 法二：**三段翻转** reverse(0,k)+reverse(k,n)+reverse(0,n)（O(n)）
两种方法在 n=10⁶、k=n/2 下实测对比；三次翻转为什么对（写一句循环不变量证明思路）？
*考察点：对撞双指针；不变量思维——HPC 里矩阵分块旋转、循环移位（SIMD 数据重排）同款。*

**C2（病虫害监控——find 的语义反转）** 实现无序向量 `find` 后思考：为什么邓课版本**自后向前**找（返回最后出现者）而不是先来者？改动成"找最先出现"并对比两种语义在 deduplicate 里的效果差异。
*考察点：接口语义的选择及其连锁影响——"最后出现"配合删除天然保留首次插入序。*

**C3（Vector 的模板化拷贝语义）** 给 Vector 加拷贝构造 `Vector(const Vector& v)` 与赋值运算符 `operator=`（deep copy：copyFrom + 释放旧 _elem）。🕷 不加会怎样（浅拷贝双析构）？用两份 Vector 互相赋值 + 程序结束验证（ASan 下观察 double-free）。
*考察点：C++ 三法则（Rule of Three）在数据结构类的落地——stage2 模块 09 的堆内存纪律进阶。*
