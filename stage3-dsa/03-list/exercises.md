# 模块 03（stage3）练习：列表 List

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。全程手写（不用 std::list）。

## A 概念题

**A1** 哨兵（header/trailer）带来哪三大红利？"空表/单节点边界矩阵"为什么被结构性消灭？
*考察点：无首末特例/边界统一/空表合法结构。*

**A2** 秩接口和位置接口的复杂度各多少？`L[i]` 出现在双重循环里意味着什么？
*考察点：O(r) vs O(1)；O(n) 伪装者实际 O(n²)。*

**A3** 向量 uniquify 用"搬留法"、列表 uniquify 用"删除法"——为什么手段不同但都是 O(n)？
*考察点：向量搬数据便宜（连续）；列表删节点便宜（改指针）。手段随结构。*

**A4** 🕷 向量归并与列表归并的成本镜像是什么？各自的"贵"在哪里、总量为何都是 O(n log n)？
*考察点：向量分免费合贵、列表分贵合免费；T(n)=2T(n/2)+O(n)。*

**A5** 列表插入排序为什么"从后向前找插入位"？相等元素的处理如何保证稳定性？
*考察点：与保序插入语义配合；"不大于即停"让相等者保持原序。*

**A6** 列表的 `find` 为什么从 p 向**前**找而不是向后？
*考察点：配合 insertB（紧前插入）的保序语义——找到即可原地接入。*

## B 动手题

**B1（哨兵版 List<T> 完整实现）** 按讲义骨架手写：
```cpp
// init() 建 header/trailer；析构 clear()+删哨兵
// insertA/insertB/insertAsFirst/insertAsLast/remove
// find(e, n, p) 自 p 向前 n 个；operator[](r) 近端走
// deduplicate / uniquify / reverse / traverse
```
测试：头插 5 个、尾插 5 个、中间 insertA 3 个 → traverse 正确；reverse 后再 reverse 还原；随机数据 uniquify（先 sort）后无相邻重复；析构无泄漏（ASan 验证）。
*考察点：哨兵设计的完整落地——全程无一处空表特判。*

**B2（🕷 四指针纪律实验）** insertA 的正确实现要写 4 个指针赋值。故意**漏写一个**（比如 `succ->pred = x`），构造最小复现：哪个操作最先崩、什么现象（断链/丢节点/悬垂）？
*考察点：指针矩阵的每一格都有职责——漏一格的现场病理。*

**B3（列表排序三连）** 在你的 List 上实现插入/选择/归并三排序：
1. 正确性：随机 1 万元素三排序结果一致（对照某一遍 traverse 采集）
2. **接驳可视化**：给节点编号，归并后编号顺序应有序而**节点地址不变**（数据零搬移的证据）
3. 计时对比：归并 O(n log n) vs 另两个 O(n²)（n=5 万可见量级差）
*考察点：三种排序在列表上的落地；splice 的本质验证。*

**B4（快慢指针）** 实现 `middle()`：快指针两步慢指针一步，返回中点。用它给归并做"分"。奇偶长度各测；空表/单节点表呢？
*考察点：无下标结构找中点的标准技巧。*

## C 挑战题

**C1（LRU 缓存——位置接口的经典应用）** 用你的 List + 哈希（可用手写或 std::unordered_map 做 O(1) 定位）实现 LRU：
- `get(key)`：命中则把节点**接驳到表头**并返回
- `put(key, value)`：存在则更新+接驳头；不存在则头插，超容则删尾
两个操作都要摊 O(1)——**哪一步靠哈希、哪一步靠列表**？
*考察点：哈希定位 + 列表 O(1) 接驳/删除的组合拳——OS 页置换、Redis 淘汰的同款内核。*

**C2（循位置改写循秩——性能陷阱实测）** 同一个任务"把每个元素乘 2"：
1. 位置接口版：`for (p = first; p != trailer; p = p->succ) p->data *= 2;`
2. 秩接口版：`for (int i = 0; i < n; i++) L[i] *= 2;`
10 万元素各计时——差多少？为什么？
*考察点：O(n) vs O(n²) 的隐形伪装；接口选择的性能后果。*

**C3（约瑟夫环）** n 人围圈从 1 报数到 m 出列、下一人续报，求出列顺序。用 List 实现（出列=remove O(1)，接续=succ，绕圈=trailer 前回到 header 后继）。对照数组版（每出列一个要 O(n) 搬移/标记），n=10000、m=3 计时对比。
*考察点：循环链表的自然形态；O(1) 删除 vs O(n) 搬移在环形结构上的量级差。*
