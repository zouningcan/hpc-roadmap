# 模块 05（stage3）练习：串与 KMP

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。

## A 概念题

**A1** BF 最坏 O(n·m) 的触发模式是什么形状的输入？它浪费的根源？
*考察点：AAAA/AAAB 型；i 回退 j 归零，已看信息丢弃。*

**A2** 手算 next 表（写出过程）：`"ababab"`、`"aaaaab"`、`"abcabcac"`。next[0] 为什么是 -1？
*考察点：最长相等前后缀（严格短）；-1 哨兵防死循环。*

**A3** 🕷 KMP 主循环里 i 为什么可以"永不回退"？失配时模式滑动的依据是什么？
*考察点：已匹配段=T子串=P前缀；next 给出新对齐位。*

**A4** buildNext 里 `t = next[t]` 这一行在干什么？为什么这保证构造是 O(m)？
*考察点：自匹配失配递归回退；t 单调减、总量被 ++j 配平。*

**A5** nextval 改进针对什么浪费？改进后复杂度变了吗？
*考察点：P[next[j]]==P[j] 必再失配；省常数不省阶级。*

**A6** 用"单调势能"论证写出 KMP 的 O(n+m) 证明骨架。
*考察点：i+j 只增不减、j 回退受总增量约束 ≤ 2(n+m)。*

## B 动手题

**B1（三件套实现）** 实现 `buildNext / buildNextVal / matchKMP`，对以下用例全过：
```
T="abababab", P="abab"     → 命中 0
T="aaaaaaab", P="aaab"     → 命中 4
T="abc",     P="d"         → -1
T="a",       P="a"         → 0
```
与 std::string::find 交叉验证 1000 组随机串（长度 1~50）。
*考察点：完整实现 + 预言机测试。*

**B2（手算追踪）** 对 T=`"abababab"`、P=`"abab"`：画出 KMP 每一步的 (i, j, 动作) 表（命中之前共几步？BF 同一用例几步？）。
*考察点：算法执行的纸上全息——考试形态。*

**B3（对比实验：BF vs KMP 的主场与客场）** 造三组文本×模式（各 n=10⁶）：
1. 随机串找随机模式（**客场**：两者接近）
2. T=aaa...a、P=aa...ab（**主场**：BF 最坏）
3. T=随机、P=aaa...a（大量前缀命中后失配）
分别计时 BF 与 KMP——哪组差距最大？哪组几乎无差？
*考察点：复杂度差异依赖输入形态——最坏与平均的实感。*

## C 挑战题

**C1（next 的等价定义与验证）** 证明并实验验证：`next[j]` 也等于"使得 P[0..t) == P[j-t..j) 成立的最大 t<j"。用暴力 O(m³) 版本对 100 个随机模式算 next，与你的 O(m) 版本全等断言。
*考察点：定义的换装——从"滑动能行"到"前后缀相等"；暴力预言机法。*

**C2（循环节问题——next 的应用大招）** 利用 next 表 O(1) 判断并求出串的最短循环节：
- 提示：设 `c = m - next[m]`，若 `m % c == 0` 则 P 由长度 c 的循环节组成
- 实现 `int cycleLen(const string& P)` 并测试：`"ababab"`→2、`"abcabcabc"`→3、`"abcd"`→4（无更短循环节时是自身）
*考察点：next 表的派生应用——KMP 家族里出题率最高的旁支。*

**C3（多模式一瞥：AC 自动机的思想实验）** 若要同时找 100 个模式（如敏感词表），对每个模式各跑一遍 KMP 总代价如何？查资料用一段话说明 AC 自动机（Aho-Corasick）如何用"trie + 失效指针"把 k 个模式的匹配降到 O(n + 总模式长 + 命中数)——失效指针与 next 表是什么关系？
*考察点：单模式→多模式的结构推广；grep/ids 入侵检测的真实引擎。*
