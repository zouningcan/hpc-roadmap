## 0. 一句话定位

图（graph）= **顶点 + 边**，一切"关系网"的抽象：路网、依赖关系、社交网络、网格计算。本章四件套：**遍历（BFS/DFS）→ 拓扑排序 → 最短路（Dijkstra/Floyd）→ 最小生成树（Prim/Kruskal）**——每件都是"遍历思想的变形"。

## 1. 表示：邻接矩阵 vs 邻接表

| | 邻接矩阵 `M[n][n]` | 邻接表（每顶点一条边链） |
|---|---|---|
| 空间 | O(n²)——稠密图合算 | O(n+e)——**稀疏图必选** |
| 查边 (u,v) | O(1) | O(deg(u)) |
| 枚举 u 的邻居 | O(n) | O(deg(u)) |
| 缓存 | 好 | 差（链式）→ HPC 用 CSR 压平 |

**CSR**（compressed sparse row，延伸）：三个数组把邻接表压平成连续内存——HPC 稀疏计算（HPCG！）的标准格式，Graph500 的输入也是它。

## 2. 广度优先搜索（BFS）：一圈一圈荡开

队列驱动：起点入队 → 出队时把**未访问邻居**全入队。效果：**按与起点的跳数分层**——第一次访问某顶点时，路径就是**最短跳数路径**（无权图的最短路！），复杂度 O(n+e)（邻接表）。

```
分层效果：s → [s 的邻居] → [邻居的邻居] ...（洋葱）
```

## 3. 深度优先搜索（DFS）：一条道走到黑，回头再战

栈驱动（递归 = 隐式栈）：能走多深走多深，死路回溯。副产品丰富：

- **括号序**：每个顶点有进出时刻——祖先-后代关系一查便知
- **拓扑排序**：DFS 逆后序即拓扑序（DAG 无环才有效）
- **环检测**：有向图 DFS 遇到"正在栈里的点"（back edge）= 有环
- 无向图的桥/割点、双连通分量：DFS 树 + low 链接值（考试了解思想即可）

**BFS vs DFS 一句话**：BFS 用队列保公平（层序），DFS 用栈钻深度——同一个图，两次遍历，两棵树。

## 4. 拓扑排序（DAG 专属）

给"依赖关系"排出合法执行序（选课、编译依赖、任务调度——Slurm 的依赖作业！）。两法：
1. **反复摘零入度点**（Kahn）：每次拿走入度 0 的顶点并删其出边——直观
2. **DFS 逆后序**：完成时刻晚的排前面
环存在 ⇔ 排不完 ⇔ 剩余点全有入度——**拓扑排序就是 DAG 环检测**。

## 5. 最短路

### 5.1 Dijkstra（单源、非负权）——贪心 + 优先级队列

贪心不变量：每次从"已确定集合"外取**当前 dist 最小**的顶点 u——它已不可能更近（非负权！）。然后松弛 u 的出边：

```cpp
// dist[] 初始化 INF，dist[s]=0；手写堆（模块 08 上场！）
while (堆非空) {
    u = 堆中 dist 最小的顶点; pop;
    if (u 已确定) continue;         // 懒惰删除（08 章的老朋友）
    确定 u;
    for (u 的每条边 (u,v,w))
        if (dist[u] + w < dist[v]) { dist[v] = dist[u]+w; heap.push/decrease(v); }
}
```

复杂度：二叉堆版 O((n+e) log n)。🕷 **负权边直接击穿贪心**——"确定"的顶点之后可能被负边拉低，必须换 Bellman-Ford。

### 5.2 Bellman-Ford（可负权，可测负环）

全边松弛 n-1 轮（每轮 O(e)），总 O(n·e)。原理：最短路至多 n-1 条边，第 i 轮至少确定"i 条边以内"的最短路。第 n 轮还能松弛 = 有负环。

### 5.3 Floyd-Warshall（全源，多对多）

动态规划：`d[i][j] = min(d[i][j], d[i][k]+d[k][j])`，k 从 1 扫到 n——三重循环 O(n³)，代码五行，稠密图小规模直接梭哈。

## 6. 最小生成树（MST）

连通无向图里选 n-1 条边把所有点连起来且总权最小。**切割性质**（跨任意割的最轻边必在某棵 MST 里）是两算法的共同底气：

- **Prim**（加点）：从任一点长树，每次**跨割取最轻边**拉进新点——Dijkstra 的孪生兄弟（比较的是边权而非 dist 和），堆版 O(e log n)。**稠密图优**
- **Kruskal**（加边）：所有边升序试，不构成环就收——判环用并查集（union-find）。**稀疏图优**，O(e log e)

🕷 并查集（union-find）本身是散列/数组的近亲：路径压缩 + 按秩合并 → 均摊 α(n)≈O(1)——必会手写。

## 7. 常见误区清单

1. BFS 求的是**跳数最短**，带权图里它不是最短路（那要 Dijkstra）——两者别混
2. Dijkstra 用在负权图：静默给错答案（不是崩溃）——最危险的错误；见负权先 Bellman-Ford
3. 手写堆做 Dijkstra 没有 decrease-key：就"重复 push + pop 时查已确定跳过"（懒惰删除）——这是标准工程姿势，不是 hack
4. DFS 递归写法在百万顶点的图上**爆栈**（递归深度=图深度）——OJ 大图改显式栈/增序迭代
5. Kruskal 忘了"不成环"判定：无并查集就每加一条边跑一次 BFS——复杂度爆炸
6. 邻接矩阵存稀疏图：n=1e5 时 n² 矩阵直接内存爆炸——先看 e 的量级再选表示

## 8. 与超算比赛的联系

- **Graph500**：整个 benchmark 就是巨型随机图的 **BFS 吞吐（TEPS）**——本章第 2 节在亿顶点上的性能化改造（位图去重、CSR、2D 分区）
- **HPCG**：稀疏矩阵迭代求解——CSR 格式（第 1 节延伸）的主场
- **WRF 网格**：计算网格是规则图，分区（图分割）决定 MPI 负载均衡与通信量——图论在并行化的入口
- **负载不均的图遍历**：邻居多寡悬殊 → OpenMP schedule(dynamic) 的实战理由（03 模块 A4 的实例化）
