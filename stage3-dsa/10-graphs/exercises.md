## A 概念题

**A1** n=1000、e=5000 的图该用邻接矩阵还是邻接表？n=500、e=100000 呢？各算一笔空间账。
*考察点：稀疏/稠密的判定；表示法选择。*

**A2** 对同一无向图分别跑 BFS 和 DFS，产生的"访问序"可能不同、但都合法。两者各用什么数据结构驱动？各自"下一次访问谁"的策略是什么？一句话概括两者的性格差异。
*考察点：队列 vs 栈；层序 vs 深钻。*

**A3** 无权图最短路为什么恰好 BFS 就能求？带权图 BFS 会错在哪——举一个 3 顶点的反例。
*考察点：BFS 的分层不变量；权重的破坏力。*

**A4** Dijkstra 的贪心不变量是什么？"非负权"在论证里的哪个环节被用到？负权边如何击穿它？
*考察点：贪心正确性论证；反例构造能力。*

**A5** Prim 和 Kruskal 各自"长树的姿势"是什么？给两个场景选算法：① n=1e4、e=5e7 的稠密图 ② n=1e6、e=1e6+1 的稀疏图。
*考察点：加点 vs 加边；复杂度与图形态匹配。*

## B 动手题

**B1（邻接表 + BFS/DFS）**：读入 n 顶点 e 边的无向图（`n e` 然后每行 `u v`），从顶点 0 出发：
1. 输出 BFS 序 2. 输出 DFS 序（递归版）3. 输出到各点的跳数（BFS 距离数组）
测试图：`6 7`，边 `0 1 / 0 2 / 1 3 / 2 3 / 3 4 / 4 5 / 2 5`。
*考察点：两种遍历实现；距离数组的产出。*

**B2（环检测双修）**：① 有向图：用 DFS 三色标记（白灰黑）判环——灰遇灰即环；② 无向图：用并查集+逐边判定（两端已连通则成环）。各写一个，用 `n=4, 边 0→1,1→2,2→0`（有环）和 `n=3, 边 0-1,1-2`（无环）验证。
*考察点：三色法；并查集判环——两个标准件。*

**B3（手写堆版 Dijkstra）**：模块 08 的 MaxHeap 改造（小顶 + 存 (dist,vertex) 对），实现非负权最短路，复杂度 O((n+e)log n)。测试：`5 6` 有向边 `0 1 4 / 0 2 1 / 2 1 2 / 1 3 1 / 2 3 5 / 3 4 3`，源 0，期望 dist = [0,3,1,4,7]。
*考察点：跨模块组装（08 堆 + 本章松弛）；懒惰删除姿势。*

**B4（拓扑排序）**：n 门课的先修表（`a b` = 先修 a 才能修 b），输出一个合法修课序；若存在环输出 `IMPOSSIBLE`。用 Kahn 法（入度数组+队列）实现。测试：`6 4 / 0 2 / 1 2 / 2 3 / 3 4` 与加边 `4 0` 的两版。
*考察点：Kahn 法；环 ⇔ 排不完。*

## C 挑战题

**C1（并查集 + Kruskal 完整体）**：手写并查集（路径压缩+按秩合并），实现 Kruskal：边升序、并查集判环、收 n-1 条边输出 MST 总权。测试最小例：`4 5` 无向边 `0 1 1 / 1 2 2 / 0 2 3 / 2 3 4 / 0 3 5`，期望 MST 权 = 1+2+4 = 7。
*考察点：MST 双雄之 Kruskal；并查集手写（均摊 O(α)）。*

**C2（Floyd 五行流）**：n≤200 的稠密有向图全源最短路：`d[i][j]` 初始化（边/INF），三重循环 k,i,j 松弛。测试 4 点图并抽查两对距离；回答：为什么 k 必须放最外层？（提示：d^k 的语义——"只经前 k 个中转点"）
*考察点：Floyd 的 DP 本质；循环序不是随便排的。*

**C3（考试预演：BFS 的 HPC 化改造）**：Graph500 的 BFS kernel 思想题：10⁸ 顶点、10⁹ 边的图，标准 BFS 跑不动/跑不快。回答三个优化方向：
1. 表示：邻接表（指针链）换成什么格式，为什么对缓存友好？
2. 访问判定：visited 布尔数组换成位图，省多少空间/带宽？
3. 并行：单层内的邻居展开为什么负载不均？OpenMP 的哪个 schedule 适用？（03/04 模块联动）
*考察点：经典算法 → HPC 大规模化的三板斧（表示/位运算/并行）——面试常问的"图算法怎么并行"。*
