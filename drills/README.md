# 学长突袭题库

跨模块随机抽题复习机制。题目来源：progress/progress.md 错题本中记录的知识点 + 各模块 exercises.md 的高频误区题。

## 使用规则

- 每学完 2-3 个新模块，从题库抽 3-5 题旧知识突击检查
- 旧命令忘了也算错（记忆曲线靠重复对抗）
- 答错的知识点回炉：重读对应 notes.md 小节 + 重做原题

## 题库（随错题本滚动扩充）

### 第 1 批（来自 Missing Semester L1-L2 的实战错题）

1. `sudo echo 3 > brightness` 为什么失败？正确写法？（考察：重定向由 shell 执行 / sudo 管不到 / tee）
2. 权限串 `drwxr-xr--` 逐位解释；"进入并列出目录"需要什么权限组合？（考察：目录 x=进入 r=列出）
3. `cd ~/..` 到哪？（考察：~ 是家目录不是根目录）
4. `$?` 存什么？0 代表什么？（考察：退出码语义）
5. `touch a || ls` 在 touch 失败时 ls 执行吗？（考察：|| 兜底语义）
6. `find . -name *.py`（无引号）三种下场？（考察：glob 由 shell 展开，0/1/多个匹配的不同后果）
7. bash 的 `{` 是符号还是保留字？`{echo` 会怎样？（考察：保留字必须独立成词）
8. source 与 ./ 的本质区别？为什么这么设计？（考察：进程隔离/授权；子进程只能回传 stdout+退出码）
9. 无 tmux 断线，任务死亡的完整链条？（考察：SIGHUP）
10. 默写文件操作四件套（cp/mv/mkdir/rm）作用+例子
