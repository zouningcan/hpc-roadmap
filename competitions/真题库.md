## 二、国际大赛历届赛题（视野扩展 + 面试谈资）

### 2.1 ASC（世界大学生超算竞赛，中国发起）

| 届次 | 功耗墙 | 赛题（已知） |
|------|--------|--------------|
| ASC19 | — | CESM 气候模拟、SR 图像超分（AI）、HPL/HPCG |
| ASC20-21 | **3000W** | AI 自然语言理解、PRESTO 脉冲星搜索（FAST 望远镜数据）、量子计算赛题、HPL/HPCG |
| ASC24 | — | AI 大模型、WRF 等（官网 [asc-events.net](https://asc-events.net) 往届页） |
| ASC25 | **4000W** | AlphaFold3 推理优化、RNA 甲基化位点检测、HPL/HPCG（交大冠军） |
| ASC26 | **5000W** | 引力波数值模拟（AMSS-NCKU）、量子线路仿真（QiboTN）、全球气候 ICON、世界模型 LeWM 推理优化、HPL/HPCG（**北大冠军、清华亚军**） |

> 规律：HPL+HPCG 每年必考；应用赛题从传统科学计算（气候/天文/量子）加速滑向 AI（超分→大模型→世界模型）；功耗墙逐年上调 3000W→4000W→5000W。

### 2.2 SC SCC（美国超算大会学生集群竞赛，2007 起）

- 历史总库：[SC26 Cluster Competition History](https://sc26.supercomputing.org/students/cluster-competition-history/)——**每年下拉框里有完整的 benchmark+应用+获奖名单**
- 每年标配三件套：**HPL + HPCG + IO500**（存储基准，[IO500 SCC 榜](https://io500.org/list/sc19/scc)）
- 科学应用轮换：VPIC（等离子体）、LAMMPS（分子动力学）、Quantum ESPRESSO（第一性原理）、Cardioid（心脏模拟）、PHASTA（流体）等
- 两个特色环节：**Reproducibility Challenge**（复现前年 SC 论文，测真实科研功力）+ **Mystery Application**（开赛现场才公布的神秘题，考阅读文档能力）
- 功耗帽：3000W → 近年 10000W；48 小时连续赛制

### 2.3 ISC SCC（德国超算大会学生集群竞赛）

- 2026 线上赛：**北大冠军**——赛题含 OpenFOAM（计算流体力学）、ASCOT5（聚变等离子体粒子输运模拟）（[北大基金会新闻](https://www.pkuef.org/info/1020/9234.htm)）
- 清华 2024 SC SCC 总冠军：6kW 功耗下 LINPACK/HPCG/HPCC + 科学应用（[清华新闻](https://www.cs.tsinghua.edu.cn/info/1088/6091.htm)）

## 三、模式总结（出题人视角）

**校内选拔的通用形态**（HelloHPC = Xflops 招新 = HPCGame）：
1. 签到题（拿账号/证明会 SSH）
2. 问答/杂学题（信息素养）
3. 单核优化题（位运算/算法——1 核）
4. 中规模并行题（4-8 核，OpenMP/perf）
5. 大规模实操题（128 核：跑基准/编译科学应用/写 sbatch 脚本）
6. 全程 OJ + writeup + 防打表 + Code Review

**国际赛题的通用形态**：基准三件套（HPL/HPCG/IO500）+ 科学应用 + 功耗墙 + 复现挑战 + 神秘题。

> 两者的公共知识内核 = 本仓库 stage4 的 8 个模块。**刷题的真正收益不是押题，是让"读题→定位知识点→写脚本→调优→写 writeup"这条流水线变成肌肉记忆。**

## 四、刷题建议（结合备考月计划）

1. **Xflops2024 五题当模拟考**（Week 1-2 里挑一个周末限时做）：先只读 readme 不看答案，做完对照 evaluate.py
2. **HPCGame 第一届公开题**当第二卷；题解博客在做完后读（对照思路差距）
3. ASC/SC 赛题不实操（缺集群/GPU），但**读题练"提取 Slurm 参数和评分公式"**（01-slurm C1 的扩展训练）
4. 每套题做完把新踩的坑回填 [progress/progress.md](../progress/progress.md) 错题本
