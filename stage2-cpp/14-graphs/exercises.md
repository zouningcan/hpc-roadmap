# 模块 14（stage2）练习：图与最短路

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。
> 图题铁律：**每次操作后画出 visited / dist / 队列的三行状态**。

## A 概念题

**A1** 图和树/链表的本质区别（入口与层级）？"稀疏 vs 稠密"的定义？官方的存法结论一句话？
*考察点：无根无序；边数相对 n²；稀疏表稠密阵。*

**A2** 邻接表和邻接矩阵在"空间、插边/查边、列 k 个邻居"三项上各自的表现？
*考察点：表 O(n+E)/扫链/ O(k)；阵 O(n²)/O(1)/O(n)。*

**A3** a) BFS 为什么保证无权图最短路？b) 带权图里它错在哪？c) 三算法选择口诀？
*考察点：队列层级=距离；只数边不数权重；无权BFS/带权Dijkstra/终点+A*=A*。*

**A4** 📍 Dijkstra 为什么要求**非负**权边？负边会打破它的哪条机制？
*考察点：visited 永不回头；负边能让已结算的点变更便宜。*

**A5** A* 的优先级公式？启发函数的"可采纳性"是什么、违反了会怎样？A* 与 Dijkstra 的两个定位差异？
*考察点：g+h；h 永不高估否则失优；单目标 vs 全图、需已知终点。*

**A6** "惰性重复"堆方案怎么处理降值更新？为什么最终是 O(n² log n)？无序数组版为什么反而是 O(n²)？
*考察点：只插不删、弹出验旧；堆可涨到 n² 条；找最小 O(n)×n 轮、删用交换 O(1)。*

**A7** 拓扑排序的两个官方要点（与路径的关系、环的后果）？
*考察点：不是路径只是排队；有环无解。*

## B 动手题

**B1（图的搭建与遍历）** 用邻接表（`unordered_map<string, vector<string>>`）搭官方例图 u-v-w（无向，双向加边），实现：
1. `bfs(g, start)`：打印访问序 + 每点的**层号**（距离）
2. `dfs`：递归版 + 显式栈迭代版各一
3. 验证：BFS 给出的是**最短跳数**，DFS 给出的只是**一条**路
*考察点：遍历双雄的落地；visited 集合防环。*

**B2（Dijkstra 追踪 + 实现）** 造官方 9 点带权图（A..I，含 A→H 直边 18、A→I 1、I→E 2、I→G 3、G→H 2、A→B 5）：
1. **纸笔追踪**：写出每轮"选中谁、松弛了谁、dist 表快照"（应复现官方：I=1, E=3, G=4, H=6, B=5）
2. 实现 O(n²) 数组版（无序数组扫最小）
3. 再实现**惰性堆版**（`priority_queue` 允许多份，弹出验 stale）
4. 两版结果一致？10 万元素随机稀疏图上谁快？
*考察点：算法的完整生命周期；两实现的对照。*

**B3（拓扑排序 + 环检测）** 课程先修图：C→D、B→C、A→C、A→B（A 无先修）：
1. 手推一个合法修课序并程序验证（每次输出"当前无未满足前置"的点）
2. 加一条 C→A 造环——你的实现正确报错了吗？
3. 验证官方要点：拓扑序的相邻两点之间**未必有边**
*考察点：Kahn 式实现；环=排不完；序≠路径。*

## C 挑战题

**C1（A\* 网格导航）** 100×100 网格，随机撒 20% 墙，实现三算法从左上到右下：BFS、Dijkstra（每步代价 1，等价 BFS）、**A\*（h=曼哈顿距离 |dx|+|dy|）**。统计各自**访问过的格子数**——应看到 BFS≥Dijkstra≫A\*。把 A* 的 h 改成"曼哈顿×2"（高估！）再跑：路径还最短吗？
*考察点：官方三算法探索量的可视化；违反可采纳性的现场恶果。*

**C2（word ladder——课程经典，本仓库延伸）** word→warm→worm：给定词表，每次换一个字母、要求中间词也在词表。用 BFS 求 ladder 最短步数（建图思路：每个词的 26 个"变一位"候选查哈希集合）。为什么这个问题天然属于 BFS 而不是 Dijkstra？
*考察点：把实际问题抽象成图（词=点、一字母差=边、无权）；无权最短→BFS。*

**C3（全部拓扑序——回溯收尾）** 官方 exam prep：用模块 07 的回溯**枚举全部**合法拓扑序（每层在"当前可选集"里选一个、递归、撤销）。对 B3 的先修图输出全部序；复杂度上界是多少（n 个点的排列中合法者）？
*考察点：回溯×图=枚举器；最坏 O(n!) 的排列空间——图模块与回溯模块的合流。*
