# 模块 14（stage2）参考答案

## A1

树有唯一根、严格父子层级；链表有头；**图没有入口、任意连接**（树/链表是图的特例）。稀疏：边数远小于 n²；稠密：接近完全图。官方结论：**稀疏用邻接表，稠密用邻接矩阵**。

## A2

| | 邻接表 | 邻接矩阵 |
|---|---|---|
| 空间 | O(n+E)（稀疏省） | 恒 O(n²)（无向还双份） |
| 插边/查边 | 要扫该点邻链 O(度) | **O(1)** |
| 列 k 个邻居 | **O(k)** | 扫一整行 O(n) |

## A3

a) 队列保证**按距离分层**处理：第一次到达某点时走过的边数一定最少（所有更近的点都已出队）。
b) 带权时"边少"≠"权重小"（A→H 直边 1 步 18 元 vs 绕 3 步 6 元）。
c) 无权最短 → BFS；带权、要全图 → Dijkstra；带权、已知终点、有好启发 → A*。

## A4

因为"**visited 永不回头**"：点一旦按最小 dist 结算，就假定它的 dist 已是最终值。负边能事后**降低已结算点的成本**（经它到别人的路也更便宜了），但 Dijkstra 不再重处理——正确性前提（非负）被打破，答案错。官方补充：给每边加 |x|+1 再减回的补丁也不成立（路径长数变了，减回去不再最优）。

## A5

优先级 = g(n) + h(n)（已走代价 + 到终点的估计）。可采纳性：**h 永不高估**真实剩余成本——高估则可能把更优路径压后，失去最短保证。两个定位差异：A* 只求**到单个终点**的最短路（Dijkstra 给全图）；A* 需要**事先知道终点**且有估计手段。

## A6

惰性重复：降值时**不找旧记录**，直接把新（更小）优先级插一份；弹出时检查该 dist 是否还是当前值，**过期就丢弃**。松弛最多发生 O(n²) 次（稠密），堆里最多 n² 条 → O(n² log n)。
数组版：每轮 O(n) 扫未访问最小 + O(1) 交换删除，n 轮 → O(n²)，且无堆常数——**小中规模常胜**。"选哪个结构"取决于**更新操作的频率与代价**，不是直觉。

## A7

① 拓扑序**不是图中的路径**（相邻两点可以没有边），只是满足"先其后于其前驱"的排队；② **有环则不存在**合法拓扑序——实现以"结束时仍有未放置的顶点"判环报错。

## B1 参考

```cpp
void bfs(G& g, const std::string& s) {
    std::queue<std::string> q;
    std::unordered_map<std::string,int> dist;
    q.push(s); dist[s] = 0;
    while (!q.empty()) {
        auto cur = q.front(); q.pop();
        for (auto& nb : g[cur])
            if (!dist.count(nb)) { dist[nb] = dist[cur] + 1; q.push(nb); }
    }
}
```
DFS 递归版 = 模块 12 前序变形 + visited；迭代版用显式栈（模块 03 C3 的防爆栈形态）。验证：u-v-w 图上 BFS 层号 u=0、v=w=1；DFS 可能先钻 w 再回 v——两种"合法但目标不同"的探索。

## B2 参考

追踪表（源 A，每轮选最小未访问）：选 A(0) 松弛 I=1,B=5,H=18 → 选 I(1) 松弛 E=3,G=4 → 选 E(3) → 选 G(4) 松弛 H=6（**H 从 18 降到 6——绕路胜直边**）→ 选 B(5) → 选 H(6) ✓。
数组版核心：`while 有未访问：O(n) 扫最小 → 松弛邻居 → visited`。惰性堆版：`priority_queue<pair<dist,点>,greater>`，松弛成功就 push（不管旧的），弹出时 `if (d != dist[v]) continue;` 丢 stale。随机稀疏大图上堆版通常更快（E ≪ n² 时 log 项作用在小集合上）。

## B3 参考

手推：合法序如 A, B, C, D（A 先行；B、C 依赖满足后入场）。实现（Kahn 式）：反复挑"入度已清零"的点输出并把它的出边剪掉。加 C→A 后 A/B/C 互为前置，循环结束仍有剩点 → 报"有环"。验证序≠路径：合法序 A,B,C,D 中 A→B 有边、B→C 有边，但换个合法序 A,C,...（若 C 只依赖 A）时 A→C 相邻有边、C 与下一节点可能无边——**相邻只是排队巧合，不是走图**。

## C1 参考现象

访问格子数：BFS ≈ 全图（方形波扩散）；Dijkstra（等权）与 BFS 几乎同；A* 明显更少（朝终点的椭圆/泪滴形探索区）。h×2 高估后：探索更少更"直"，但**路径不再保证最短**（可能错过绕行的更优通道）——可采纳性不是洁癖，是正确性开关。

## C3 参考

```cpp
void allTopo(std::vector<int>& order, std::vector<bool>& used /* + 入度表 */) {
    if (order.size() == n) { print(order); return; }
    for (int v = 0; v < n; v++)
        if (!used[v] && indeg[v] == 0) {          // 当前合法选择
            used[v] = true;
            for (int w : adj[v]) indeg[w]--;       // Choose
            order.push_back(v);
            allTopo(order, used);                  // Explore
            order.pop_back();                      // Unchoose
            for (int w : adj[v]) indeg[w]++;
            used[v] = false;
        }
}
```
B3 的 4 点先修图合法序数量有限（A 开头为主）；复杂度上界：每层选择 ≤ n → **O(n!)** 级的排列空间被约束剪到合法子集——回溯（模块 07）+ 图（本模块）在同一题里合流，CS106B 两大主线就此闭环。
