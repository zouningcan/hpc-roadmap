# 模块 12（stage2）练习：二叉树、BST 与 Huffman

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。
> 树题铁律：**先画树再答题**；遍历题手算结果先用程序验证。

## A 概念题

**A1** 对官方例题树（23；左 11（右 19）；右 57（右 89（左 81、右 99）））写出前序、中序、后序输出。哪个遍历对 BST 有特殊意义？
*考察点：三种 DFS；中序=升序。*

**A2** 📍 为什么 `bstInsert` 必须 `TreeNode*&`？插入实际发生在什么位置？
*考察点：写的是"空指针本身"；按引用让 root 成为父节点 child 字段的别名。*

**A3** BST 删除三案例各自怎么处理？课程标准里双孩子删除用左子树的什么、为什么之后还要递归？
*考察点：叶剪/子顶/左max顶替+递归删；否则左子树出现重复值。*

**A4** BST 的 search 最坏 O(n) 在什么输入下发生？自平衡树（AVL/红黑）靠什么把最坏钉在 O(log n)？哪个标准库容器用它？
*考察点：退化链表；旋转维持高度差；std::map/set。*

**A5** 释放整棵树为什么用**后序**？前序版本死在哪一步？
*考察点：先烧孩子后烧自己；前序先删根，找孩子时解引用已删内存。*

**A6** 🕷 a) 前缀自由码的定义？b) 为什么"字符只放叶子"就自动保证前缀性质？c) Huffman 树的"失衡"为什么反而是优点？
*考察点：无码是另一码前缀；祖先关系即前缀关系；高频挂浅码短。*

**A7** Huffman 建树为什么必须配优先队列？两个平局的树不同时，什么必须随数据一起传输？
*考察点：每轮取最小两棵；不同的树同样最优——解码端必须重建同一棵。*

## B 动手题

**B1（遍历四件套 + 验证）** 构造官方例题树，实现 pre/in/post-order（递归）与 level-order（队列）：
1. 验证 A1 的三个手算结果
2. 层序输出是什么？
3. 再造一棵**普通**（非 BST）二叉树跑中序——输出还有序吗？"中序=升序"的前提是什么？
*考察点：四种遍历落地；BST 性质与遍历的关系。*

**B2（BST 全家桶）** 实现 `bstInsert`（递归版）+ `contains`（BST 版：只走一边）+ `bstDelete`（三案例）：
1. 插入 50, 30, 70, 20, 40, 60, 80 后中序打印——升序？
2. 依次删除：叶（20）、单孩子节点（造一个）、双孩子节点（50）——每次删除后中序仍升序且元素正确？
3. `contains` 普通树版（全搜）与 BST 版（折半走）各写一个——BST 版复杂度？
*考察点：官方指定的完整实现；删除后中序校验法。*

**B3（forestFire 与内存纪律）** 实现 `forestFire(TreeNode*& root)`（后序释放 + 置空），配合构造器制造 1 万节点随机 BST：
1. 释放后打印 root——nullptr？
2. 用 valgrind 或地址消毒（`g++ -fsanitize=address`）验证无泄漏
3. 🕷 故意改成前序释放，用 ASan 跑——报告什么错误？
*考察点：正确的树释放；ASan 抓悬垂的现场（stage1 模块 07 工具回归）。*

**B4（Huffman 全流程——纸笔）** 对 `"abracadabra"`（a×5, b×2, r×2, c×1, d×1）：
1. 手工执行建树：每轮写下"取出哪两棵、合并成多少"
2. 画出最终树，标出每个字符的编码
3. 手工编码全文，数一数总位数；对比 ASCII 的 88 位，压缩率？
4. 用你的码表手工解码前 10 位验证能还原
*考察点：建树算法的手感——考试形态；压缩率的量级。*

## C 挑战题

**C1（Huffman 编程实现：Assignment 7 微缩版）** 用 `std::priority_queue` 实现完整编解码：
```cpp
// 接口建议：
std::string encode(const std::string& text);        // 返回 "010111..." 位串
std::string decode(const std::string& bits, /* 树或码表 */);
```
1. 建 forest：`priority_queue<pair<权重, TreeNode*>, ..., greater<>>`（🕷 树本身不可比较——比**权重**）
2. encode：DFS 生成每字符的路径串，拼接
3. decode：从根按位走，到叶输出并回根
4. **往返测试**：对任意输入串 `assert(decode(encode(s)) == s)`
5. 报告 "happy hip hop" 的压缩率 vs 官方 34/104
*考察点：堆+树+DFS 的三合一工程；性质测试（往返恒等）。*

**C2（退化实验：BST 的链表时刻）** 依次插入 1..100000 造退化 BST，测 contains(99999) 计时；再随机打乱插入顺序造平衡树，同测。差多少倍？`std::set`（红黑树）在两同样序列下呢——为什么它没有退化？
*考察点：最坏/平均的活体对照；自平衡的价值可视化。*

**C3（树的递归三谜题——官方 exam prep 风格）** 实现三个递归函数并写测试：
1. `int height(TreeNode*)`——注意**空树**该返回什么？（官方 debug 题：忘判空的版本直接段错误；空树习惯返回 -1，让单节点高度为 0）
2. `int countLeaves(TreeNode*)`
3. `bool isBST(TreeNode*)`——🕷 不能只比较 node 与左右孩子：`{20, 左子树里藏 25}` 的反例；正确解法用 (min,max) 区间向下收紧
*考察点：树递归的标准形态；isBST 的区间法——"局部满足≠全局满足"。*
