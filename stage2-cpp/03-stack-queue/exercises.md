# 模块 03（stage2）练习：栈与队列

> 分层：A 概念 / B 动手 / C 挑战。🕷 = 高频易错。

## A 概念题

**A1** 依次 push 10、20、15、12 后全部弹出——输出顺序？这个过程体现栈的哪个性质、哪个经典应用？
*考察点：LIFO；逆序/反转序列。*

**A2** a) 为什么"用 vector 模拟栈能用但不该用"？官方说的"抽象的力量"三重收益是什么？b) 栈故意不提供 find/中间插入，这个"限制"的价值在哪？
*考察点：语义表达、防错、实现可替换。*

**A3** 🕷 `std::stack<int> s; int x = s.pop();` 错在哪？正确的"取值并弹出"怎么写？`std::queue` 的对应二连是什么？
*考察点：std 的 pop 不返回值；top()+pop() / front()+pop()。*

**A4** 🕷 解释为什么 `for (int i = 0; i < q.size(); i++) { q.pop(); }` 无法排空队列。两种正确写法？
*考察点：边遍历边缩容；预存 size / while 判空。*

**A5** 后缀求值遇到运算符时，"先弹出的是左操作数还是右操作数"？为什么 `-` 和 `/` 特别容易错？
*考察点：弹出顺序=右先；不可交换运算。*

**A6** 为什么 range-for 不能遍历 `std::stack`？这是库的缺陷还是设计？
*考察点：限制操作集的贯彻——不提供迭代器=不许你绕过 LIFO 纪律。*

## B 动手题

**B1（手算+机验：后缀求值追踪）** 先**纸笔**算出结果，再用 B3 的程序验证：
```
a) 3 5 2 * + 12 2 3 * / -        （官方例题）
b) 7 2 - 3 *
c) 5 1 2 + 4 * + 3 -
```
每步画出栈的内容快照（a 至少画 6 步）。
*考察点：栈状态追踪——考试与调试的基本功。*

**B2（字符串反转与队列轮转）**：
```cpp
// 1) 用 std::stack<char> 反转字符串：reverse("muffins") == "sniffum"
// 2) 队列轮转：把 {1,2,3,4,5} 前 2 个挪到队尾 → {3,4,5,1,2}
//    提示：dequeue 后再 enqueue 同一个值
// 3) 🕷 经典陷阱复现：往队列放 1..6，跑
//    for (int i = 0; i < q.size(); i++) { cout << q.front(); q.pop(); }
//    输出几个数？为什么？
```
*考察点：栈/队列的基本操作组合；size 动态缩小的现场。*

**B3（后缀表达式求值器——本模块主作业）** 实现完整版：
```cpp
#include <stack>
#include <string>
#include <sstream>
double evalPostfix(const std::string& expr);
// 输入空格分隔的 token：数字或 + - * /
// 返回计算结果；输入非法时 throw std::invalid_argument("...")
```
要求处理官方点名的四类坏输入：坏 token、操作数不足、除零、结束时栈里 ≠ 1 个数。
测试：B1 的三例 + 至少 3 个坏输入（空串、`1 +`、`1 0 /`、`1 2 3 +`）。
*考察点：栈的完整应用 + 防御式编程（每个失败模式都有明确检测）。*

## C 挑战题

**C1（括号匹配——栈的另一经典应用）** 判断字符串的 `()[]{}` 是否合法嵌套（`(]` 非法、`([)]` 非法、`([])` 合法）。算法三行：左括号压栈；右括号弹栈比对是否配对；结束时栈必须空。写实现 + 测试（至少含 `([)]`、空串、只有右括号三类边界）。
*考察点：栈对"嵌套结构"的天然建模——这也是编译器语法检查的内核。*

**C2（用两个队列实现一个栈）** 设计 `MyStack`：只准用两个 `std::queue<int>` 实现 push/pop/top。提示：push 后做一次"翻转轮转"，让最新元素始终待在队首。复杂度各是多少？
*考察点：用 A 结构模拟 B 结构——对语义的深度理解（也常见于面试）。*

**C3（感受"调用栈"是真栈：递归爆栈实验）**：
```cpp
int depth(int n) { return n == 0 ? 0 : 1 + depth(n - 1); }
// main 里：cout << depth(100000);
```
跑 `depth(100000)`，观察段错误（stack overflow）；再用 `ulimit -s`（查/改栈大小，如 `ulimit -s 65536` 后重跑）。递归深度受什么物理限制？DFS 类赛题怎么防（提示：显式栈改迭代）？
*考察点：数据结构"栈"与内存区域"栈"的同构——HPC 代码里真实的死法。*
