**A2** 🕷 逐条判断合法/非法并解释：

**A5** a) 悬垂指针的定义与官方比喻？b) 为什么"程序退出时 OS 会回收"不能成为不 delete 的借口？c) `delete` 与 `delete[]` 的配对规则？

## B 动手题

**B1（官方练习 1：从零写一个类）** 设计 `class BankAccount`：
- private 成员：`_owner`（string）、`_balance`（double，不可为负）
- 构造函数两个（默认 + 带参）、析构函数（打印一条"[owner] 账户关闭"）
- `deposit(amount)`（负数拒绝并报错）、`withdraw(amount)`（**余额不足拒绝**）、`balance() const`、`owner() const`
- 头/源分离（.h 带 include guard；.cpp 用 `BankAccount::`）
- main 里完整演练，观察析构消息在何时打印
*考察点：官方要求的完整类全要素；setter 内的业务校验（封装的实际收益）。*

**B2（指针地图实验）** 逐条预测输出再验证：
```cpp
int x = 42, y = 99;
int* p = &x;
int* q = &y;
std::cout << *p << " " << *q << "\n";   // 1) 预测
*p = 50;
std::cout << x << "\n";                  // 2) 预测
q = p;                                   // q 改指 x
std::cout << (*p == *q) << " " << (p == q) << "\n";  // 3) 预测
int* r = nullptr;
// *r = 5;                               // 4) 取消注释会怎样？（段错误现场）
int arr[4] = {1,2,3,4};
int* s = arr;                            // 数组名衰变
std::cout << s[2] << " " << *(s + 2) << "\n";  // 5) 预测
```
*考察点：解引用改本体、指针比较的两层含义、nullptr、衰变与下标=偏移。*

**B3（swap 三代目：指针版）** 模块 01 写过引用版 swap，本讲官方要求指针版：
```cpp
void ptrSwap(int* a, int* b) { /* 用 * 解引用交换 */ }
// 调用：ptrSwap(&x, &y);
```
对比两版调用语法，并回答：引用版和指针版在"能改调用者变量"这点上殊途同归，差别在哪（谁能为空、调用方语法、可否重指向）？
*考察点：传指针=显式地址传递；引用/指针的分野。*

**B4（ArrayBasedStack 完整实现与压测）** 按讲义第 3 节实现（含 `*2+1` 扩容、先删后指、const 成员函数）：
1. push 100 万个数验证正确（对照 std::stack）
2. 🕷 **泄漏对照实验**：故意注释掉 `delete[] _elements;`（扩容处），在 main 里循环 new 一万个这种栈再销毁——用 `cat /proc/self/status | grep VmRSS`（或 top）观察内存；恢复 delete 再对照
3. 故意把扩容写成 `*2`，构造初始容量 0 的版本看它卡死在哪
*考察点：官方案例的三个细节亲手验证；泄漏的量化现场。*
