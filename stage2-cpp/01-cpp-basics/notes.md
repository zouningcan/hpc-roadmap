## 0. 一句话定位

C++ 是**编译型**语言（一次性翻译成机器码，区别于 Python 的逐行解释）；类型必须**显式声明且不可中途变脸**。这两个属性正是 HPC 选它当主语言的原因：编译期抓错、零解释器开销。

## 1. 程序结构

```cpp
#include <iostream>      // 尖括号 = 系统标准库
// #include "console.h" // 双引号 = 本地/课程库（我们不用 Stanford 库，全用尖括号）
using namespace std;     // 省去 std:: 前缀；课程代码常这么写，工程代码更推荐 std::cout

int main() {             // 执行永远从这里开始；成功返回 0
    cout << "Hello, world!" << endl;
    return 0;
}
```

- `cout` 是输出**流**，`<<` 把东西依次"倒"进去；`endl` 换行（没有它输出会粘在一起）
- 大括号定界代码块（不是 Python 的缩进），块内缩进一层是风格纪律
- 注释：`//` 单行、`/* */` 块。注释写**为什么**，不复述代码

## 2. 变量与类型：显式、终身制

```cpp
int count = 0;        double pi = 3.14;
char c = 'x';         // 单引号单个字符
string s = "hello";   // 双引号字符串（字符串是对象，见第 5 节）
bool ok = true;
```

🕷 三大坑：

1. **未初始化的变量是垃圾值**（不是 0！）——`int x; cout << x;` 打印的是内存残渣。声明即初始化是铁律
2. 类型终身制：`x = 3.14`（x 是 int）会被截断，不报错但静默出错
3. 重新赋值**不重写类型**：`int x = 3; x = 5;` ✅；`int x = 3; int x = 5;` ❌ 重定义

## 3. 流控制

```cpp
while (i < 5) { ... }                    // 括号必须有
for (int i = 0; i < 5; i++) { ... }      // 三段：初始化一次/条件每次前查/后语句每次尾跑
for (char ch : s) { cout << ch; }        // range-for 遍历容器元素
if (a == 1) { ... } else if (a == 2) { ... } else { ... }
```

🕷 **本讲最著名的坑**：

```cpp
if (num == 1 || 2)      // ❌ 恒真！解析成 (num==1) || (2)，2 是 truthy
if (num == 1 || num == 2)  // ✅ 两侧都要写 ==
```

比较运算符：`< <= > >= == !=`（注意 `<=` 不是 `=<`）。布尔：`&& || !`（单个 `&` `|` 是位运算，含义完全不同）。

**作用域（scope）**：变量活在声明它的块里——`for (int i...)` 的 i 循环结束即死。想在循环后用 i，就在循环外声明。

## 4. 函数与原型

```cpp
int square(int x) { return x * x; }   // 返回值必须被接住或打印，不能白调
void greet() { cout << "hi"; }        // void：无返回值；裸 return; 可提前退出
```

编译器**自上而下**读代码：在定义之前调用会报错。两个解法——调整定义顺序，或**提前放原型**（函数签名 + 分号）：

```cpp
int square(int x);      // 原型：告诉编译器"有这号人物"
int main() { return square(5); }
int square(int x) { return x * x; }
```

（对应我们 stage1 的体验：shell 里的函数要先 source 定义才可用——"先声明后使用"是编译型语言的通用纪律。）

## 5. 字符串：字符数组 + 对象

两个身份：**连续字符块**（下标 0 到 n-1）+ **对象**（带成员函数，用点号调用）。

```cpp
string s = "hello there";
s[0]                      // 'h' —— 可以读
s[0] = 'H';               // 也可以改！C++ string 是【可变的】（Python/Java 不可变，改=造新的）
s.length()                // 12（成员函数，点号调用；size() 同义）
s.substr(1, 4)            // "ello"：从下标 1 起取 4 个字符
s.find("there")           // 6：找不到返回 string::npos
s.append("!")             // 尾部追加（等价 s += "!"）
```

🕷 两个陷阱：

1. **越界不设防**：`s[100]` 编译能过、运行有概率打印垃圾或直接段错误（segmentation fault）——C++ 把边界检查的责任交给你（HPC 要性能的代价）
2. **拼接规则**：`+` 两边**至少一个**是 string 对象。`"ab" + "cd"`（两个字面量）编译失败；`string("ab") + "cd"` ✅

**遍历的两种姿势**：`for (int i = 0; i < s.length(); i++)`（有下标信息）vs `for (char ch : s)`（简洁但拿不到位置）。

## 6. char 的另一面：整数

字符底层就是 ASCII 整数：`int('a')` = 97、`int('A')` = 65。于是：

```cpp
ch >= 'a' && ch <= 'z'      // 判断小写（比 islower 手写版）
ch - 'a' + 1                // 字母序号（a=1）——用 ('a' - 1) 表达意图，拒绝魔法数字 96
```

标准库 `<cctype>`：`isalpha/isdigit/islower/isspace/ispunct` 判定 + `toupper(ch)/tolower(ch)`。

## 7. 传值 vs 传引用——本模块的灵魂

```cpp
void twice(int n)  { n = n * 2; }     // 传值：n 是【副本】，改了白改
void twice(int& n) { n = n * 2; }     // 传引用：& 让 n 成为调用者变量的【传送门】，改动落地
```

**官方比喻**：传引用的 `&` 像给函数开了一扇直通调用者变量的**传送门（portal）**——你在门这边改，门那边真的变了。官方"洗劫宝藏"例子：传值时函数只能抢副本，真宝库无损；传引用时宝库真被清零。

**为什么需要传引用（两大动机）**：

1. **返回多个结果**：函数只能 return 一个值，`mySwap(a, b)`、求二次方程两个根——靠引用参数"带出"额外结果
2. **效率**：传值 = 整份拷贝。传一个 1GB 的字符串，拷贝一次 1GB；传引用只传约 64 位的"门牌号"。**HPC 热路径上，传大对象的值拷贝是隐形性能杀手**

注意区分：Stanford 库的 `toUpperCase(s)` / `toupper(ch)` 都是**传值返回新值**——`toUpperCase(s);` 单独调用什么也没发生，必须 `s = toUpperCase(s);` 接住返回值（官方原话强调的坑）。

## 8. 常见误区清单

1. 未初始化变量当 0 用——是垃圾值
2. `if (x == 1 || 2)` 恒真——每侧都要比较
3. `s[i]` 不查边界——越界是未定义行为
4. `"a" + "b"` 编译错——至少一边要是 string 对象
5. 忘接返回值：`toUpperCase(s);` 白调
6. 大对象传值——热路径性能杀手；只读大参数写 `const string&`（既免拷贝又防误改）
7. 作用域：循环头里声明的 i，循环后不存在
